# 배포

로컬에서는 `scripts\run.bat`으로 실행합니다. HubSpot 웹훅을 받으려면 HTTPS 공개 주소가 필요하므로 Cloudflare Tunnel이나 단일 FastAPI 컨테이너를 사용합니다.

운영에서는 한 프로세스만 백그라운드 폴러와 발송 워커를 실행해야 합니다. 여러 웹 프로세스를 쓸 경우 워커 전용 프로세스를 하나만 두고 나머지에서는 관련 환경변수를 끕니다.

**마이그레이션은 컨테이너가 뜰 때 알아서 돕니다.** 엔트리포인트가 `scripts/init_db.py`를
먼저 돌리고 실패하면 uvicorn을 띄우지 않습니다 — 스키마가 안 맞는 채로 트래픽을 받는 일이
없습니다. 개발 PC에서 손으로 돌릴 필요가 없는데, 사내망이 5432/6543 아웃바운드를 막고 있어서
어차피 노트북에서는 붙지 않습니다. 스키마를 먼저 눈으로 보고 싶으면 `MIGRATE_ON_START=false`.

배포 전 확인:

1. PostgreSQL `DATABASE_URL` (마이그레이션은 기동 시 자동)
2. `PUBLIC_BASE_URL`과 인증 설정
3. HubSpot 웹훅 서명 검증용 secret
4. SMTP 테스트 주소로 한 건 발송
5. 실제 HubSpot 단계 ID 확인
6. `/healthz`, `/logs`, `/operations` 확인
7. `/app` 확인 — 콘솔이 뜨지 않고 503이면 React 번들이 빠진 것입니다

컨테이너는 React 콘솔을 스스로 빌드합니다(Dockerfile의 node 스테이지). 번들은 git에 없으므로
`docker build` 없이 소스만 배포하는 방식이라면 `npm --prefix frontend ci && npm --prefix frontend run build`
를 먼저 돌려야 `/app`이 응답합니다.
