# 문제 해결

```powershell
.\.venv\Scripts\python.exe -m src.cli doctor
.\.venv\Scripts\python.exe -m src.db.migrate
```

- 접수 확인은 갔지만 상세 답변이 안 보임: `/messages`에서 `작성 실패`를 확인하고 `/logs`를 봅니다.
- 승인 후 메일이 안 감: SMTP 사용자·앱 비밀번호·보낸 주소를 확인합니다. 상태는 `send_failed`로 남습니다.
- HubSpot에 기록이 없음: 메일 배달과 CRM 기록은 분리되어 있습니다. 로그에서 타임라인 기록 실패를 확인합니다.
- 티켓이 안 잡힘: 티켓 단계가 `HUBSPOT_TICKET_STAGE_NEW`와 같은지, 연결된 연락처와 문의 본문이 있는지 확인합니다.
- Slack이 안 옴: `SLACK_ENABLED=true`, `APPROVAL_CHANNEL=slack`인지 확인한 뒤 상세 초안이 `pending_approval`이 되었는지와 채널 ID를 확인합니다. 접수 시점에는 알림을 보내지 않습니다.
- Slack이 반복됨: 테스트는 강제로 Slack이 꺼지고, 운영 초안은 `slack_notified_at`이 비어 있을 때만 전송됩니다. 먼저 중복 실행 중인 옛 배포가 없는지 확인하고 즉시 멈추려면 `SLACK_ENABLED=false`로 재시작합니다.
- 실제 계정 전환: HubSpot Private App 토큰과 두 티켓 단계 ID만 실제 계정 값으로 바꾼 뒤 수동 동기화로 먼저 검증합니다.
