# PERSO 결제·계정 FAQ·응대 가이드

> 이 문서는 결제/구독/계정 관련 고객 문의의 사실·절차와 응답 예시를 담습니다.
> 플랜 가격 숫자는 [[perso_pricing]], 환불 금액 계산식은 [[perso_faq_refund_cancellation]] 가 담당합니다. 여기서는 절차와 응대만 다룹니다.
> 응답 예시의 플레이스홀더(`유저이름`, `[고객명]`, `#XXXX-XXXX` 등)는 실제 값으로 치환하세요.

## 결제 내역 및 영수증 발급

(a) 핵심 절차

- 고객이 직접 PERSO 내에서 결제 내역 조회 및 영수증·청구서를 다운로드할 수 있습니다.
- 경로: PERSO 로그인 → 좌측 상단 배너 클릭 → **결제 관리(Billing Management)** → 청구서 내역에서 원하는 결제 항목 클릭 → **청구서 다운로드** 또는 **영수증 다운로드**.
- 답변 시 해당 화면 스크린샷을 함께 첨부하면 이해에 도움이 됩니다.

(b) 한국어 고객 응답 예시

```
안녕하세요, 유저이름 고객님!
Perso AI를 이용해주셔서 감사합니다.

📋 결제 내역 조회 및 다운로드 방법

2. 청구서 내역에서 원하는 결제 항목 클릭
3. ‘청구서 다운로드’ 혹은 ‘영수증 다운로드’ 클릭

추가로 궁금하신 점이 있으시면 언제든지 편하게 문의 주세요!

## 청구서(인보이스) 정보 변경

(a) 핵심 절차

- 인보이스/청구서에 기업명, 주소, Tax ID 등을 반영하려면 고객이 직접 **Manage billing 페이지에서 정보를 먼저 업데이트**해야 합니다.
- 경로: 설정 → Subscription → **Manage billing** → 상단 정보 입력란에 기업 정보 입력 후 업데이트 → 하단 청구 내역에서 원하는 항목 클릭 후 다운로드.
- 변경 가능 항목: 이름(Name), 이메일(Email), 주소(Address), 전화번호(Phone), 세금계산서 번호(Tax ID).
- 유의: 정보 업데이트 **이전에 이미 발행된** 청구서에는 변경 내용이 자동 반영되지 않습니다. 입력 후 저장까지 완료해야 반영됩니다.

(b) 한국어 고객 응답 예시

```
안녕하세요, 고객님.
Perso AI를 이용해주셔서 감사합니다.

청구서(인보이스)에 표시되는 기업명·주소·Tax ID 등의 정보는
설정 → Subscription → Manage billing 페이지에서 직접 업데이트하실 수 있습니다.

상단 정보 입력란에 변경할 정보를 입력하고 업데이트하시면,
이후 발행되는 청구서부터 해당 정보가 반영됩니다.
(업데이트 이전에 이미 발행된 청구서에는 자동으로 반영되지 않는 점 양해 부탁드립니다.)

추가로 궁금하신 점이 있으시면 언제든 편하게 문의해 주세요.
감사합니다.
Perso AI 문의지원팀 드림
```

> 운영자 참고: 이미 결제 완료되어 발행(Finalized)된 인보이스는 직접 수정이 불가합니다. 정보 수정 재발행이 필요한 경우, 원본 인보이스에 **Credit Note(Reason: Other, 금액 처리 방식: Credit their balance)** 를 발행해 회계적으로 상쇄한 뒤, Customer 프로필 정보를 먼저 수정하고 동일 통화·동일 금액으로 신규 인보이스를 생성합니다. `Refund their card` 선택 시 실제 카드 환불이 발생하므로 절대 선택 금지. Add internal note(요청일·요청자·수정 내용·담당자)는 반드시 기재하고, 처리 내역(원본/Credit Note/수정본 번호)을 티켓·내부 시트에 기록합니다. 인보이스 변경은 진행 전 PM 확인을 1회 거칩니다. 세금계산서가 필요한 한국 고객은 Stripe 인보이스와 별도로 세금계산서 처리 절차를 병행합니다.

> 운영자 참고: 단건 결제(추가 구매 등 PaymentIntent)는 Stripe에서 인보이스가 자동 생성되지 않습니다. 사후 발행이 필요하면 인보이스를 생성·Finalize한 뒤 **Mark as paid outside of Stripe(Out-of-Band)** 로 처리해 이중 매출 집계를 방지합니다. 이미 결제한 고객에게 결제 요청 메일이 가지 않도록 `Finalize only`를 선택하고 payment page 링크는 체크 해제합니다.

## 결제 실패 — Discover/Diners Club 카드 미지원

(a) 핵심 사실

- PERSO 신규 구독 결제는 싱가포르 법인([SG] Perso AI)을 통해 처리됩니다. 싱가포르 Stripe 계정은 **Discover 및 Diners Club 카드를 지원하지 않으며**, 해당 카드로 결제 시 "지원되지 않는 카드" 오류로 거절됩니다.
- 이는 Stripe 정책상 싱가포르 계정에서 발생하는 제약으로, 당사 측에서 개별 처리할 수 있는 방법은 없습니다.
- 싱가포르 법인에서 현재 지원하는 카드: **Visa, Mastercard, American Express, UnionPay**.
- 처리 절차: 고객 가입 이메일을 수집 → Stripe에서 결제 실패 내역 조회 → 실패 사유가 Discover/Diners Club 미지원으로 확인되면 아래 안내 발송.

(b) 한국어 고객 응답 예시

```
안녕하세요, Perso AI입니다.

결제 실패 건을 확인하기 위해 내부 결제 시스템을 조회한 결과,
사용하신 카드가 Discover 카드로 확인되었습니다.

현재 Perso AI는 싱가포르 법인을 통해 결제가 처리되며,
싱가포르 기반 Stripe 계정에서는 Discover 카드를 지원하지 않습니다.
이 점으로 인해 결제가 거절된 것으로 확인됩니다.

현재 이용 가능한 결제 수단은 아래와 같습니다.
- Visa
- Mastercard
- American Express
- UnionPay

위 카드 중 하나로 다시 시도해 주시면 정상적으로 결제가 진행됩니다.
추가로 궁금하신 점이 있으시면 언제든지 문의해 주세요.

감사합니다.
Perso AI 팀 드림
```

> 운영자 참고: Stripe 정책상 Discover/Diners Club/JCB 카드는 미국·캐나다·일본·영국 및 EEA 등 특정 국가 계정에서만 수신 가능하며 싱가포르는 미포함. 고객에게 대안(지원 카드로 재시도)을 명확히 제시합니다.

## 결제 금액이 책정 가격을 넘는 경우 (카드사 수수료)

(a) 핵심 사실

- PERSO는 Stripe를 통해 명시된 금액(예: 원화 기준)만 정확히 청구하며, PERSO 영수증에 기재된 금액이 실제 청구 금액입니다.
- 카드 청구 금액이 더 큰 경우, 차액은 PERSO가 부과·확인할 수 없는 비용으로 **카드사가 해외 결제 처리 과정에서 자동 부과한 수수료**입니다: 해외 서비스(해외 결제) 수수료, 국제 브랜드 수수료(VISA/Master/JCB 등), 네트워크 이용료/소액 환전 수수료 등.

(b) 한국어 고객 응답 예시

```
안녕하세요 고객님.
Perso AI를 이용해주시고 문의 주셔서 감사합니다.

결제 금액과 카드 청구 금액의 차이에 대해 안내드립니다.

Perso AI는 글로벌 결제 시스템(Stripe)을 통해 결제가 처리되며,
저희 측에서는 고객님께 영수증에 명시된 금액을 정상적으로 청구합니다.

다만 일부 국내 신용·체크카드의 경우 해외 결제망을 사용할 때,
카드사 측에서 아래와 같은 추가 수수료가 자동으로 부과될 수 있습니다.
- 해외 서비스 수수료(해외 결제 수수료)
- 국제 브랜드 수수료(VISA/Master/JCB 등)
- 네트워크 이용료 또는 소액 환전 수수료

이 추가 금액은 Perso AI가 부과하거나 확인할 수 없는 비용이며,
카드사에서 해외 결제 처리 과정 중 자동으로 발생하는 요금이라는 점 참고 부탁드립니다.

추가로 궁금한 점 있으시면 언제든 편하게 문의해주세요 :)
감사합니다.
```

## 실제 결제 금액과 영수증 간 차이가 있을 시

(a) 핵심 사실

- 위 ‘카드사 수수료’ 케이스와 동일한 원인이나, 고객이 영수증 vs 카드 승인 내역의 차이를 직접 지적하는 상황에 사용합니다.
- 차이 발생 원인: PERSO가 해외 결제 인프라(Stripe)를 사용해 카드사가 해외 결제 건으로 분류, 카드사 정책상 해외/국제 브랜드 수수료 추가, 결제 승인 시점과 매입 시점의 환율 차이, 법인카드의 다른 수수료 정책 등.
- PERSO에서는 카드사가 별도 부과한 수수료·환율 차이에 대해 금액 조정이나 재영수증 발급이 어렵습니다. 정확한 차액 사유는 고객이 카드사(또는 법인카드 발급사)에 ‘해외 결제 수수료 및 환율 적용 내역’으로 문의하도록 권장합니다.

(b) 한국어 고객 응답 예시

```
안녕하세요, 고객님.
결제 금액과 카드 승인 금액 간 차이로 불편을 드려 죄송합니다.
해당 건에 대해 확인한 내용을 안내드립니다.

Perso AI는 결제 시 Stripe 결제 시스템을 통해 명시된 금액만 정확히 청구하고 있으며,
Perso AI에서 발행된 영수증에 기재된 금액이 당사에서 실제로 청구한 금액입니다.

다만, 카드사 승인 내역에서 확인되는 추가 금액은 Perso AI에서 부과한 금액이 아니라,
카드사 또는 카드 브랜드(Visa 등) 측에서 별도로 적용한 해외 결제 관련 수수료 또는
환율 차이로 발생한 것으로 보입니다.

이러한 차이는 다음과 같은 경우에 발생할 수 있습니다.
- 해외 결제 인프라(Stripe) 사용으로 카드사에서 해외 결제 건으로 분류하는 경우
- 카드사 정책에 따라 해외 결제 수수료 또는 국제 브랜드 수수료가 추가되는 경우
- 결제 승인 시점과 카드 매입 시점의 환율 차이
- 특히 법인카드 사용 시 개인카드와 다른 수수료 정책이 적용되는 경우

카드사에서 별도로 부과한 수수료나 환율 차이에 대해서는
금액 조정 또는 재영수증 발급이 어려운 점 양해 부탁드립니다.
정확한 차액 사유 확인을 위해서는 사용하신 카드사(또는 법인카드 발급사)에
해외 결제 수수료 및 환율 적용 내역으로 문의해 주시기를 권장드립니다.

추가로 도움이 필요하시거나 확인이 필요한 사항이 있다면 언제든지 편하게 문의 주세요.
감사합니다.
Perso AI 드림
```

## 비밀번호 변경 방법

(a) 핵심 절차

- 로그인한 상태에서 계정 설정을 통해 변경합니다.
- 경로: 우측 상단 user 아이콘 클릭 → 계정 설정 → 비밀번호 수정 → 이메일로 코드 전송 → 이메일에서 Verification code 확인 → PERSO에 코드 입력 → 수정.

(b) 한국어 고객 응답 예시

```
안녕하세요, USER이름 님.
Perso AI를 이용해주시고 문의 남겨주셔서 감사합니다.

비밀번호 변경 방법에 대해 아래와 같이 안내드립니다.
1. 우측 상단 user 아이콘 클릭 → 계정 설정
2. 비밀번호 수정 클릭 → 이메일로 코드 전송
3. 이메일에 접속 → Verification code 확인
4. perso에 해당 코드 입력 → 수정

위의 절차로 진행해 보시길 바랍니다.
안내 드린 내용이 도움이 되었길 바랍니다.
감사합니다.
```

## 비밀번호를 잊어버렸을 때 (로그인 전 재설정)

(a) 핵심 절차

- 로그인 화면에서 가입한 이메일 입력 → Continue → **Forgot Password?** 클릭 → 가입한 이메일로 인증코드 발송 → 코드로 재설정.
- 인증코드 메일이 보이지 않으면 스팸 메일함 확인을 함께 안내합니다.

(b) 한국어 고객 응답 예시

```
안녕하세요, 고객님.
Perso AI를 이용해주셔서 감사합니다.

비밀번호를 잊으신 경우 아래 절차로 재설정하실 수 있습니다.
1. 로그인 화면에서 가입한 이메일 입력 후 Continue 클릭
2. ‘Forgot Password?’ 클릭

## 분쟁(Dispute)·사기 의심 케이스

(a) 핵심 사실

- Dispute는 고객이 카드사를 통해 결제에 이의를 제기(Chargeback)하거나, Stripe의 사기 방지 시스템(Radar 등)이 이상 패턴을 자동 감지하는 경우 발생합니다.
- 증상: 고객이 "환불을 요청하지 않았는데 환불됐다" 또는 "구독이 자동 취소됐다"고 문의. 이 경우 고위험 거래로 자동 환불 및 보안 차단(블랙리스트) 처리가 동반될 수 있습니다.
- 응대 원칙(준수 필수): "도난/분실 카드", "사기꾼" 등 직접 표현 금지(법적/명예훼손 소지), 구체적 카드번호·거래 세부 공개 금지, 블랙리스트 해제 가능성 제시 금지, 감정적 대응 금지. 대신 **시스템(결제 대행사·카드사)의 자동 판단**으로 설명하고, 최종 판단 권한이 카드사에 있음을 안내하며, 공손하지만 단호하게 대응합니다.
- 단계별 응대: ① 계정 확인 요청(실제 사용 이메일 + 환불 영수증 스크린샷) → ② 상황 설명(고위험 자동 탐지·보안 차단·새 결제수단으로 재구독 시 복구 가능성 안내) → ③ 추가 항의 시 최종 입장(자동 시스템 결정으로 임의 변경 불가, 카드사/Stripe Support 안내).

## Stripe Dispute 환불 처리 시 안내 (간이 버전)

(a) 핵심 사실

- Stripe가 결제 수단을 고위험(high-risk)으로 자동 판정하면 거래가 dispute 상태로 분류되어 자동 즉시 환불되고, 해당 구독도 함께 취소됩니다.
- 서비스 계속 이용을 원하면 **다른 결제 수단(다른 카드)** 으로 재구독하도록 안내합니다. (위 분쟁 케이스의 간단 단일 응답이 필요할 때 사용)

(b) 한국어 고객 응답 예시

```
안녕하세요 고객님.
Perso AI 문의 주셔서 감사합니다.
고객님이 문의하신 결제 건 관련 상황 안내드립니다.

Stripe 결제사 측에서 고객님이 사용하신 결제 수단이 고위험군(high-risk)으로
자동 판정되면서, 해당 거래가 dispute(이의 제기) 상태로 분류되었습니다.
이로 인해 결제는 자동으로 즉시 환불 처리되었고,
고객님의 Perso AI 구독도 함께 취소된 상태입니다.

서비스 이용을 계속 원하신다면,
👉 다른 결제 수단(다른 카드)을 이용하여 구독을 다시 진행해주시면
정상적으로 이용하실 수 있습니다.

혹시 재결제 과정에서 어려움이 있다면 언제든 편하게 문의해주세요 :)
감사합니다.
```

## 생성 결과 오류 보상

(a) 핵심 사실/절차

- Fast Speed 시간은 무제한이 아니므로 크레딧을 사용해 생성한 결과물에 **기능 이슈로 이상이 있을 때** 보상 여부를 검토합니다.
- 판단 기준: ‘현격한 품질 저하로 에러라 할 만한 경우’에 한해 보상(해당 생성에 든 크레딧만큼 크레딧 지급). 그렇지 않으면 환불 없이 현재 서비스에서 생성 가능한 퀄리티 수준을 설명합니다.
- 안내 후 동일 사유 2번째부터는 환불 불가(본인 책임 뉘앙스 문구 추가). 공식 미지원 언어(예: 조지아어 등) 사용 시 5분 이하로 분할 제작하면 정상 동작 가능성이 있음을 함께 안내합니다.

(b) 한국어 고객 응답 예시

```
안녕하세요, 고객님.
Perso AI를 이용해주셔서 감사합니다.

확인 결과, 이번 건은 결과물 품질 이슈로 판단되어
해당 생성에 사용된 크레딧만큼 보상 크레딧을 지급해 드렸습니다.

참고로 원본 언어가 공식 지원 언어가 아닌 경우 결과 품질이 저하될 수 있으며,
5분 이하의 길이로 영상을 분할하여 제작하시면 정상 동작 가능성이 높으니
이용에 참고 부탁드립니다.

감사합니다.
Perso AI 드림
```

> 운영자 참고: 보상 여부는 주관적 판단이 들어가므로 내부 논의가 필요한 케이스. 동일 고객 반복 보상은 지양하고, 첫 안내 시 "다음 생성부터는 본인 책임" 뉘앙스를 명확히 남깁니다.
