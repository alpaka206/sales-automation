# CS 응대 정책 & 톤앤매너 (인바운드 문의 답변)

> 출처: PERSO CS 운영 정책 / 답변 매뉴얼. 인바운드 문의(더빙·결제·환불·계정·오류 등) 답변에 적용.

## 응대 원칙

- **당일 해결 지향, 24시간 내 처리.** 즉답이 어려운 사안(환불 심사·보안·계약·법무·내부 확인 필요)은 "정확히 확인 후 다시 안내드리겠다"고 약속하고 예상 소요(영업일 N일)를 알린다.
- **모르면 지어내지 않는다.** 확실하지 않은 정보는 "정확한 확인 후 다시 연락드리겠습니다"로 응대. 지식 베이스(knowledge_base)에 있는 사실만 인용.
- **고객 문의 언어로 회신.** 한국어 문의엔 한국어, 영어 문의엔 영어.

## 톤앤매너 — 긍정·해결 중심

- **과도한 사과 금지.** "정말 죄송합니다", "불편을 드려 죄송합니다"를 남발하지 말 것. 잘못 인정보다 **해결해 드렸다는 긍정적 뉘앙스** + 이용 감사 표현으로 전환.
- **"불가능합니다" 금지.** 정책상 어려운 경우에도 **대안을 1개 제시**한다.
- **고객 탓 표현 금지.** 잘못을 지적하기보다 더 나은 방법을 안내.

### 금지 표현 → 권장 표현

| ❌ 금지 | ✅ 권장 |
|--------|--------|
| "정말 죄송합니다" / "불편을 드리게 된 점 죄송합니다" | "문의 주신 내용으로 처리 도와드렸습니다" (해결 강조) / "이용해 주셔서 감사합니다. 더 좋은 서비스로 보답하겠습니다" |
| "불가능합니다" | "현재 정책상 어렵지만, 대안을 제시해 드릴게요" / "현재는 지원하지 않지만, 이런 방법은 어떠신가요?" |
| "모르겠네요" | "정확한 확인 후 다시 연락드리겠습니다" |
| "잘못하셨네요" / 고객 탓 | "더 나은 방법을 안내해 드릴게요" |

## 환불·구독취소 응대 요령

- 환불 문의는 먼저 **결제일·플랜·사용 시작 여부**를 확인하고, 정확한 가능 여부/금액은 내부 심사 후 안내(영업일 5~10일). 공식 환불정책 URL을 메일에 직접 첨부하지 말 것.
- 해지/환불 의사엔 정책상 가능함을 인정하되 **재이용 대안(플랜 변경·사용 팁·기간 연장)** 을 1개 제시해 정중히 재고를 유도. 상세 템플릿은 [[perso_faq_refund_cancellation]].

## 제품 라우팅

- 어떤 제품(더빙 / Studio / Live Chat) 문의인지 불확실하면 **사용 시나리오를 1줄로 먼저 확인**하고 그에 맞는 제품 1개만 안내. 모든 제품을 나열하지 않는다.
