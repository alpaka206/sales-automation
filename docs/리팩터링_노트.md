## `src/api/web/routes.py` (866줄) → `api/web/routes/` 패키지 (완료)

가장 긴 파일이었고 **패키지로 정식 분할 완료.**

- `routes/_shared.py` — templates, `esc`, 상수(`TRACKED_STATUSES`)
- `routes/dashboard.py` — `/` 대시보드 + `_dashboard_context`
- `routes/messages.py` — `/messages*` 목록·상세·승인액션 + `_message_detail_context`/`_messages_list_context`
- `routes/knowledge.py` — `/knowledge*` CRUD·이력 + `_slugify`/`_parse_csv`/`_snapshot_revision`
- `routes/icp.py` — `/icp-rules*`
- `routes/outbound.py` — `/outbound*`, `/prospects*`
- `routes/settings_page.py` — `/settings*` + `_settings_context`/`_mask_value`
- `routes/unsubscribe.py` — `/unsubscribe`(공개)
- `routes/__init__.py` — 서브 라우터를 `router` 로 합침 (`main.py` 는 그대로 `from .web.routes import router`)

### 분할 시 함께 처리한 것 (참고용)
- 서브모듈 상대 import 깊이는 **4단계**(`from ....common.config import settings`).
- 테스트가 이 모듈의 내부 심볼을 **모듈 속성으로 직접 패치**하므로, 패치 경로를 서브모듈로 갱신:
  `src.api.web.routes._dashboard_context` → `...routes.dashboard._dashboard_context`,
  `...SessionLocal` → 해당 서브모듈(`...routes.messages/knowledge/outbound/icp.SessionLocal`),
  `..._settings_context` → `...routes.settings_page._settings_context`,
  `..._reset_kb_cache` → `...routes.knowledge._reset_kb_cache`.
  (test_web_ui, test_settings_page, test_knowledge_routes, test_outbound_routes, test_icp_rules, test_unsubscribe — 약 20곳)
- 웹 라우트 테스트 53개 통과, 전체 598 passed / 1 failed(환경 의존 google 미설치 1건뿐).

### 추가 개선 여지(선택)
- 장기적으로 테스트가 내부 컨텍스트 빌더를 패치하지 않도록 **의존성 주입**으로 전환하면 모듈-속성 패치 결합이 풀려 유지보수가 더 쉬워짐.
