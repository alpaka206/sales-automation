# 주요 도입 케이스 (영업 참고용)

> **외부 메일에 고객사명 직접 명시는 NDA 검토 후에만 가능.** 아래는 내부 컨텍스트 — 답장에서는 "국내 대기업·글로벌 브랜드 도입 사례가 있다" 정도로 일반화해서 표현하세요.

## 엔터프라이즈 TF 운영 중인 고객사

| 고객사 | 영역 | 활용 시나리오 |
|--------|------|--------------|
| **LG (Global Impact TF)** | 디스플레이·전자 | 글로벌 마케팅 콘텐츠 다국어 더빙 |
| **올리브영** | 이커머스·H&B | 브랜드 콘텐츠 다국어 확장 |
| **삼성** | 종합 전자 | 글로벌 콘텐츠 제작·배포 |
| **아모레퍼시픽** | 화장품·뷰티 | 글로벌 캠페인 영상 다국어화 |

## 도입 패턴 분석

- 공통점: **자체 콘텐츠 팀 보유 + 글로벌 시장 확장 단계 + 다국어 자막·더빙 수요**
- 미디어·이커머스·뷰티·B2C 브랜드 중심
- 단순 "번역" 이 아니라 **음성 클로닝·립싱크·자막 동기화까지 워크플로우 자동화** 가 핵심 선택 이유

## 비-이상적 케이스 (조심해야 할 시그널)

- 1회성 영상만 더빙하려는 개인·소상공인 → Creator 플랜 자가 가입이 더 적합 (엔터프라이즈 트랙으로 끌면 양쪽 다 시간 낭비)
- 실시간 라이브 통역만 필요한 케이스 → Dubbing 이 아니라 **Livechat** 트랙으로 라우팅
- 음성 합성·TTS 만 단독 필요 → PERSO 의 강점이 잘 안 살아남 (다국어 풀스택이 가치). 다른 솔루션 추천이 더 정직할 수 있음

## 답장 시 어조

- 케이스 스터디 언급: "유사한 산업의 글로벌 브랜드에서 다국어 더빙 워크플로우를 자동화한 사례가 있어 관련 자료를 미팅 때 공유드릴 수 있습니다."
- 고객사 시그널을 못 잡았을 때 → 사용 시나리오·예상 사용량·운영 조직 규모 3가지 먼저 확인.
- 경쟁사 비교 질문 → 직접 비교 (X사 vs PERSO) 는 메일에서 자제. "워크플로우 자동화 범위·다국어 모델 품질·엔터프라이즈 운영 옵션에서 차이를 만들고 있다" 정도로 추상화.
