# PERSO 정책 변경·오류 대응 FAQ

> 작성 가이드: 본문은 정책 사실과 고객 응대 템플릿만 담습니다. 플랜 가격 숫자는 perso_pricing.md 가 담당하므로 여기서 재기재하지 않습니다. 톤앤매너 — 죄송 남발 금지, "불가능" 대신 대안 제시.

## 무제한 → 크레딧 / Low Speed 정책 (점검 이후)

핵심 사실:
- 기존 무제한 플랜에는 **공정 사용 정책(Fair Use Policy)**이 적용되어, 과도한 사용이 감지되면 24시간 뒤 자동 해제되는 일시적 제한이 있었습니다.
- 점검 이후 공정 사용 정책을 완화하고 **완전 무제한 생성 정책**으로 전환되었습니다. 무제한 생성 자체는 그대로 유지됩니다.
- 안정적 운영을 위해 **크레딧(고속 생성 시간) / Low Speed** 2단계 속도 체계가 도입되었습니다.
  - **크레딧**: 잔여 시간 동안 가장 빠른 속도로 영상 생성.
  - **Low Speed**: 크레딧 소진 시 자동 전환. 속도만 느려질 뿐 생성은 중단 없이 계속 가능.

> 운영자 참고: 내부 표기 변천 — "Fast Speed"(빠른 생성 시간) 명칭이 이후 "크레딧(Credit)"으로 변경됨. 고객 회신 시 최신 표기인 "크레딧"을 우선 사용.

한국어 응답 예시:
```
안녕하세요 고객님.
Perso AI 문의 주셔서 감사합니다.
문의 주신 하루 생성 제한 및 무제한 정책 변화에 대해 안내 드립니다.
현재 무제한으로 제공되고 있는 것이 맞지만 모든 사용자의 안정적인 사용성을 위해 공정 사용 정책(Fair Use Policy)이 적용되고 있습니다. 공정 사용 정책은 사용자의 과도한 사용이 감지될 경우에 24시간 후에 자동으로 해제되는 일시적인 제한을 뜻합니다.
하지만 금일 점검 이후부터는 Perso AI의 플랜 정책이 개선되면서, 기존의 공정 사용 정책을 완화하고 고객님께서 더욱 자유롭게 생성하실 수 있도록 완전 무제한 생성 정책으로 전환되었습니다.
이번 업데이트로 인해 고객님께서는 필요하신 만큼 자유롭게 더빙·생성 작업을 진행하실 수 있습니다.
다만, 안정적인 서비스 제공을 위해 크레딧 / Low Speed 개념이 도입되었습니다.

⚡ 크레딧: 제공된 빠른 생성 시간이 남아 있는 동안 가장 빠른 속도로 영상 생성이 가능합니다.
🕓 Low Speed: 크레딧이 모두 소진되면 자동으로 Low Speed로 전환됩니다. 속도만 느려질 뿐, 생성은 중단 없이 계속 가능합니다.

즉, 완전 무제한 생성은 그대로 유지되며, 단지 속도가 크레딧 기반 / Low로 구분되어 운영되는 방식으로 바뀌었다고 이해해주시면 됩니다.
추가로 궁금하신 점이 있으시면 언제든지 편하게 문의해주세요 :)
감사합니다.
```

## 크레딧 / Low Speed 기능 안내 (Creator 플랜 이상)

핵심 사실:
- Creator 플랜 이상에서는 매월 크레딧이 제공됩니다.
- 크레딧 사용 시간 동안 영상이 가장 빠른 속도로 생성되며, 소진 시 **Low Speed(저속 모드)**로 자동 전환됩니다.
- Low Speed 제약: **한 번에 최대 5분**, 대기열 미지원, 동시 처리 미지원. 단, 생성 자체는 중단 없이 계속 가능(무제한 유지).
- 월간 대량 고속 생성이 필요하거나 전체 작업을 크레딧 기반으로 진행해야 하는 경우 **엔터프라이즈 플랜(맞춤형 리소스)** 권장.

한국어 응답 예시:
```
안녕하세요 😊, Perso AI를 이용해주셔서 감사합니다.
문의 해 주신 [고객님의 문의(예: 크레딧, Low Speed)]에 대한 답변 드립니다.
Creator 플랜 이상에서는 매월 크레딧이 제공 됩니다.
이 크레딧 사용 시간 동안에는 영상이 가장 빠른 속도로 생성되며, 할당된 시간이 모두 소진되면 저속 모드(Low Speed)로 자동 전환되어 영상 생성은 계속 가능하지만 속도가 느려집니다. 또한 저속 모드에서는 한 번에 생성 가능한 길이가 5분 이하로 제한되며, 대기열 및 동시 처리 기능은 제공되지 않습니다.
즉, Creator 플랜 이상 고객님께서는 크레딧이 소진된 이후에도 서비스 중단 없이 계속해서 무제한 생성이 가능하다는 점 참고 부탁드립니다.
만약 월간 대량의 고속 생성이 필요하시거나, 전체 작업을 크레딧 기반으로 진행해야 하는 경우에는 맞춤형 리소스를 제공하는 엔터프라이즈 플랜을 권장드립니다.
추가로 궁금하신 점이 있으시면 언제든지 편하게 문의 주세요!
감사합니다. Perso AI 드림
```

## "왜 무제한 생성이 사라진 거죠?" 문의

핵심 사실:
- 크레딧 정책은 기존 공정 이용 정책을 완화해 더 안정적·쾌적한 생성을 위해 도입된 기능.
- 업데이트 이후에도 무제한 생성 혜택은 그대로 유지되며, 크레딧 소진 후에도 Low Speed로 중단 없이 계속 생성 가능.

한국어 응답 예시:
```
안녕하세요 고객님. Perso AI 문의 주셔서 감사합니다.
문의 주신 무제한 생성 및 크레딧 정책 관련 문의에 대해 안내드립니다.
현재 크레딧 정책은 고객님께서 더 안정적이고 쾌적하게 생성 작업을 하실 수 있도록 기존 공정 이용 정책(Fair Use Policy)을 완화하는 방향으로 새롭게 도입된 기능입니다.
업데이트 이후에도 고객님께 제공되는 무제한 생성 혜택은 그대로 유지되고 있으며, 크레딧 기반 생성 시간이 소진된 이후에도 Low Speed로 서비스 중단 없이 계속 생성 가능하다는 점 참고 부탁 드립니다.
더 나은 환경을 제공드리기 위해 지속적으로 개선해 나가겠습니다.
```

## Booster 수치 변경 문의 + 환불 대응

핵심 사실:
- 크레딧 기능 도입으로 기존 Booster 중심 구조가 더 높은 생성 속도를 제공하도록 재설계됨.
- 이에 따라 일부 Booster 수치가 조정되었으나, 대신 크레딧(고속 생성 시간)이 제공되어 전체 생성 효율은 향상되도록 구성.
- 시나리오: Booster 동시 처리량 감소로 손해라고 느껴 환불 요청.

한국어 응답 예시 — 수치 변경 안내:
```
안녕하세요 고객님. Perso AI 문의 주셔서 감사합니다.
문의 주신 Booster 기능 수치 변경에 대해 안내드립니다.
최근 업데이트로 도입된 크레딧 기능은 기존 Booster 중심 구조를 개선하여 더 높은 생성 속도를 제공하기 위한 방식으로 재설계되었습니다.
크레딧 도입에 따라 일부 Booster 수치가 조정되었지만, 대신 고객님이 활용하실 수 있는 크레딧이 제공되며 전체적인 생성 효율이 향상되도록 구성되어 있습니다.
업데이트 과정에서 고객님께서 혼란을 겪으셨을 수 있다는 점 이해하며, 더 나은 사용 경험을 제공드릴 수 있도록 지속적으로 개선하겠습니다.
추가 문의가 있으시면 언제든 말씀해주세요 :)
감사합니다.
```

> 운영자 참고: Booster 하향 관련 환불 요청도 동일하게 1차(정책 설명) → 2차("현재 구독 플랜 기준 1개월 크레딧 일괄 지급") 순으로 방어한다.

## 공지 미수신 / 동의 없이 플랜 변경 문의

핵심 사실:
- 정책 변경은 11월 24일(배포 7일 전)부터 공지사항 및 FAQ로 안내됨. 다만 웹사이트 공지만으로 전달이 충분치 않았던 점은 인정하고 향후 개선(영향 받는 기존 구독자 대상 최소 14일 전 이메일 발송 + 대시보드 알림) 예정.
- 기존 공정 사용 정책: 일일 한도 도달 시 생성 자체 차단. 새 정책: 크레딧 소진 후에도 무제한 생성 가능(차단 없음).
- 영상 길이 제한: **크레딧 최대 30분/영상, Low Speed 최대 5분/영상**. 5분 이하로 분할하면 오히려 기존보다 더 많은 작업 가능.
- 요금 증액 없이 실질적 무제한이 제공되는 변경임.

한국어 응답 예시 — 기존 구독자 변경 문의:
```
안녕하세요, Perso AI를 이용해주시고 문의 주셔서 감사합니다.
해당 내용은 11월 24일(배포 7일 전)부터 공지사항 및 FAQ를 통해 안내되었습니다. 다만 웹사이트 공지 내용이 유저님들에게 효과적으로 전달되지 않아 아쉬운 점이 있습니다. 차후 운영 개선 시 참고하겠습니다.
기존 공정 사용 정책은 일일 한도 도달 시 생성 자체를 차단했으나, 새로 도입한 정책은 크레딧 사용량 소진 후에도 무제한으로 생성할 수 있는 구조입니다. 단일 영상 최대 길이가 5분이지만, 영상을 5분 이하의 길이로 분할하여 생성한다면 오히려 기존보다 더 많은 작업이 가능합니다.
문의 주신 문구는 실질적으로 무제한으로 제공 되는데 요금 증액이 없는 부분에 대한 표현이라고 생각해주시면 감사하겠습니다.
이 점 참고하시어 이용해보시기 바라며, 추가 문의사항 있으시면 편하게 요청하여 주시기 바랍니다.
감사합니다.
```

> 운영자 참고 (고강도 클레임 / 연간 구독자 대상 상세 대응안):
> - 영상 길이 제한 정리: 크레딧 최대 30분/영상, Low Speed 최대 5분/영상.
> - 제시 옵션 ① 보상 크레딧 지급(현재 플랜 1개월분 상당) + 연간 구독 유지, 또는 ② 비례 환불(실제 사용량 제외, 잔여 전액·수수료 없음).
> - 고객이 요구할 수 있는 "이전 정책 복구 / Low Speed 30분 허용 / 상위 플랜 무상 업그레이드"는 형평성·서버 리소스·선례 관리상 수용 어려움 → 위 두 옵션으로 유도.
> - 처리 SLA 예: 보상 옵션 24시간 내 지급, 환불 옵션 사용량 확인 후 3영업일 내 처리.

## 크레딧 과금 단위 변경 (분 → 초, Fast Speed → 크레딧)

핵심 사실 (변경 후 기준):
- 차감 단위 명칭: 빠른 생성 시간(Fast Speed) → **크레딧(Credit)**.
- 더빙: 1초당 1크레딧 / 립 더빙: 1초당 3크레딧(3배 가중치 유지).
- 4K(UHD) 이상 해상도: 기본 차감량의 3배(기존 동일).
- STT(음성·영상 텍스트 변환): 1초당 0.2크레딧 / 음성 분리(Audio Separation): 1초당 0.5크레딧.
- 추가 크레딧 구매: 60크레딧 단위(60/120/180...). **Pro 플랜만** 구매 가능, Starter·Creator는 미지원(필요 시 상위 플랜 업그레이드 안내).
- 분→초 전환에 맞춰 플랜별 지급 크레딧도 함께 조정되어, 실제 생성 가능한 영상 길이는 이전과 동일하게 유지됨.

한국어 응답 예시 — 크레딧이 빨리 소진된다는 문의:
```
안녕하세요, Perso 문의지원팀입니다.
과금 방식이 분(min) 단위에서 초(sec) 단위로 변경되었습니다.
예를 들어 1분 30초짜리 영상을 더빙하면 기존에는 2크레딧이 차감되었지만, 변경 이후에는 90크레딧이 차감됩니다.
이 변경에 맞춰 플랜별 지급 크레딧도 함께 조정되었으므로, 실제 생성 가능한 영상 길이는 이전과 동일하게 유지됩니다.
마이페이지 또는 서비스 상단에서 현재 잔여 크레딧과 월 지급량을 확인하실 수 있습니다.
감사합니다.
```

한국어 응답 예시 — "빠른 생성 시간이 사라졌나요?":
```
안녕하세요, Perso 문의지원팀입니다.
이전에 '빠른 생성 시간'으로 표시되던 항목이 '크레딧'으로 명칭이 변경되었습니다.
기능 자체가 없어진 것이 아니라, 보다 직관적으로 사용량을 확인할 수 있도록 명칭과 단위를 개선한 것입니다.
앞으로는 크레딧 단위로 사용량을 확인하실 수 있으며, 기존과 동일하게 플랜별 매월 크레딧이 지급됩니다.
추가로 궁금하신 점이 있으면 말씀해 주세요. 감사합니다.
```

## STT / 음성 분리 신기능 안내

핵심 사실:
- 립싱크 명칭이 **립 더빙(Lip Dubbing)**으로 변경됨 — 고객 대응 시 '립 더빙'으로 통일.
- 신기능: **음성·영상 텍스트 변환(STT, Speech to Text)** — 업로드 파일을 텍스트로 변환, 화자별 스크립트 분리·자막 추출 지원. **음성 분리(Audio Separation)** — 화자별 음성/배경음/효과음을 트랙 단위로 분리, 원하는 트랙만 합성·다운로드.
- STT·음성 분리는 **번역 과정이 없는 기능** → 도착 언어 설정 없이 파일 업로드 후 바로 생성. "언어 설정은 어디서 하나요?" 문의 시 별도 언어 설정이 없음을 안내.
- 무료 플랜에서도 무료 제공 크레딧 범위 안에서 사용 가능.

> 운영자 참고:
> - STT·음성 분리는 **저속 모드(Low Speed) 미지원**. 저속 모드는 더빙·립 더빙에서만 사용 가능. 크레딧을 모두 소진하면 STT·음성 분리 이용 불가, 다음 결제일 충전 후 이용 가능.
> - 기능별 필수 사용량 제한 없음(STT만 또는 음성 분리만으로 크레딧 전부 소진 가능).
> - 기존 '프로젝트' 메뉴는 사라지고 '더빙 & 립 더빙 / 음성·영상 텍스트 변환 / 음성 분리'로 분리됨.
> - 번역설정창의 '립싱크 생성' 체크 기능은 사라졌고, 홈에서 '립 더빙' 생성하기로 진입해야 립 더빙이 생성됨.

## 비례배분(업그레이드 시 크레딧 지급) 문의

핵심 사실:
- 업그레이드 시 지급 크레딧 = **상·하위 플랜의 차액 × 남은 기간 비율**(비례 지급). 업그레이드가 빠를수록 남은 기간이 길어 더 많이 지급됨(당일 100%, 1주 후 약 77%, 2주 후 약 55%, 3주 후 약 32%).
- 지급은 업그레이드 완료 즉시이며 바로 사용 가능. 다음 결제일부터는 업그레이드된 플랜의 정규 지급량이 매월 제공됨.
- **Studio 크레딧과 Dubbing(빠른 생성 시간)은 서로 다른 시스템 체계** → 분리해서 안내.
- 업그레이드 비용은 이미 결제한 기간의 잔여 금액 기준 비례 계산분만 청구되며, Stripe 정상 정산 절차로 자동 처리.

> 운영자 참고: 더빙 영역은 고객 회신 시 "크레딧" 대신 "빠른 생성 시간 / Fast Speed / 분" 표현을 사용한다(매뉴얼 지침). 구체 차액 수치(예: Starter→Creator Dubbing 105분 등)는 계산 시점에 따라 달라지므로 "예시이며 실제 지급량은 계산 시점에 따라 달라질 수 있음"을 명시한다.

## 생성 이슈 보상 정책

핵심 사실:
- 크레딧 기반(Fast Speed)으로 생성하여 크레딧을 소모한 건에 한해 적용. Slow Speed 생성, 고객 입력값(스크립트·원본 음성·언어 선택 등) 오류, 템플릿에 존재하는 기능 문의는 제외.
- 보상 원칙: **환불이 아닌 동일 수량 크레딧 지급**. 단순 품질 불만족·기대치 차이는 대상 아님.
- 보상 인정 기준(하나 이상 충족 시 더빙팀 검토): 번역/더빙이 의미 전달 불가 수준으로 붕괴 / 음성 출력 비정상(무음·심각한 깨짐·반복 오류) / 더빙이 영상 내용과 전혀 무관 / 시스템 오류로 정상 생성 불가.
- 보상 제한: 동일 생성물 기준 1회 한정, 동일 사유 재요청 불가, 보상 후 추가 품질 클레임 불가.

> 운영자 참고:
> - 커뮤니케이션 원칙: "품질 보장" 표현 금지, "현재 서비스에서 생성 가능한 품질 범위" 기준으로 설명, 보상 후 이후 생성물은 사용자 책임임을 명시.
> - 비공식 지원 언어(예: 조지아어)가 원인인 경우 5분 이하 분할 생성을 안내하고, "해당 안내 이후 발생하는 생성 결과에 대해서는 추가 보상 또는 환불이 어렵습니다"를 고지.
> - 판단이 애매한 경우 'AI 품질 특성' 기준으로 보상 불가 원칙 적용. 더빙 품질 판단은 더빙팀.
