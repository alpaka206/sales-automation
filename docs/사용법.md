# 사용법

Sales Automation 시스템의 일상적인 사용 방법을 설명합니다.

## 시스템 개요

이 시스템은 세 개의 에이전트로 구성되어 있습니다:

### 1. 인바운드 에이전트

HubSpot CRM으로 들어오는 문의를 자동으로 처리합니다.

**동작 흐름:**
1. HubSpot에 새 연락처/딜이 생성되면 n8n 워크플로가 감지
2. AI가 문의 내용을 분석하고 카테고리 분류 (문의, 데모 요청, 파트너십 등)
3. 분류된 카테고리에 해당하는 **회사 안내 문서**(`knowledge_base/`)를 자동으로 골라 함께 참고
4. AI가 답장 이메일 초안을 작성
5. Slack/Teams에 승인 카드가 도착
6. 사용자가 **승인** / **수정** / **거절** 중 선택
7. 승인되면 이메일이 자동 발송되고 HubSpot에 기록

> 안내 문서 추가 방법은 아래 **회사 안내 문서 관리** 섹션 참고.

### 2. 아웃바운드 에이전트

잠재 고객을 발굴하고 첫 연락 이메일을 작성합니다.

**지원하는 소스:**
- **CSV 파일** — 수동으로 정리한 리드 목록
- **YouTube** — 채널 검색으로 잠재 파트너 발굴
- **LinkedIn CSV** — Sales Navigator 내보내기 파일
- **LinkedIn 댓글** — 경쟁사 게시물 댓글 작성자 (별도 활성화 필요)

**동작 흐름:**
1. 매일 09:00에 n8n 스케줄이 아웃바운드 파이프라인 실행
2. 소스에서 후보를 가져온 뒤 중복 검사 (90일 이내 연락한 이메일은 건너뜀)
3. AI가 ICP(이상적 고객 프로필) 점수를 매기고 기준 미달 시 건너뜀
4. 통과한 후보에게 개인화된 이메일 초안 작성
5. Slack/Teams에 승인 카드 도착
6. 승인 후 발송

### 3. 리포트 에이전트

두 에이전트의 활동을 요약합니다.

- **일간 리포트**: 매일 18:00에 생성 및 발송
- **주간 리포트**: 매주 토요일 09:00에 생성 및 발송
- 발송 채널: Slack + 이메일 (설정된 경우)

## 메시지 승인

모든 AI 작성 메시지는 발송 전에 사람의 승인이 필요합니다.

### Slack에서 승인하기

1. 지정된 Slack 채널에 승인 카드가 도착합니다
2. 카드에는 다음 정보가 표시됩니다:
   - 카테고리 (인바운드 답장 / 아웃바운드 첫 메일)
   - ICP 점수 (아웃바운드인 경우)
   - 이메일 제목과 본문 미리보기
3. **Approve** 버튼: 그대로 발송
4. **Reject** 버튼: 발송하지 않음

### Teams에서 승인하기

Teams를 사용하는 경우에도 동일한 카드 형태로 도착합니다.
`TEAMS_WEBHOOK_URL`을 설정하면 자동으로 Teams로 전환됩니다.

## 아웃바운드 리드 추가 방법

### CSV 파일로 추가하기

1. 다음 형식의 CSV 파일을 준비합니다:

```csv
name,email,company,domain,country,notes
김영희,kim@example.kr,예시회사,example.kr,korea,PyCon에서 만남
```

2. CSV 파일을 프로젝트 폴더 내 원하는 위치에 저장합니다 (예: `data/leads.csv`)

3. n8n 워크플로에서 아웃바운드 실행 시 `source=manual_csv`, `filters={"path": "data/leads.csv"}` 전달

또는 API를 직접 호출합니다:
```powershell
curl -X POST http://127.0.0.1:8000/run/outbound `
  -H "X-Internal-Token: <토큰>" `
  -H "Content-Type: application/json" `
  -d '{"source": "manual_csv", "filters": {"path": "data/leads.csv"}}'
```

### LinkedIn Sales Navigator 내보내기

1. Sales Navigator에서 리드 목록을 CSV로 내보냅니다
2. 파일을 프로젝트 폴더에 저장합니다
3. `source=linkedin_csv`로 실행합니다

### 필터 사용

모든 소스에서 공통 필터를 사용할 수 있습니다:

```json
{
  "path": "data/leads.csv",
  "domains_allow": ["example.kr"],
  "domains_block": ["competitor.com"],
  "countries": ["korea", "japan"],
  "min_audience": 1000
}
```

- `domains_allow`: 이 도메인만 포함 (화이트리스트)
- `domains_block`: 이 도메인 제외 (블랙리스트)
- `countries`: 이 국가만 포함
- `min_audience`: 최소 구독자/팔로워 수

## 회사 안내 문서 관리 (`knowledge_base/`)

요금제·환불 정책·제품 소개·자주 묻는 질문 같은 **회사의 사실 자료**를 마크다운 파일로 보관하는 곳입니다. 인바운드 문의를 받으면 AI가 분류 후 이 폴더에서 **해당 분류에 속한 문서만 골라** 답장 초안을 작성할 때 참고합니다.

### 파일 추가하기

1. `knowledge_base/` 폴더에 새 마크다운 파일을 만듭니다 (예: `요금제.md`).
2. 파일 맨 위에 다음과 같이 frontmatter를 적습니다:

   ```markdown
   ---
   title: 2026 요금제
   categories: [pricing_question, purchase_inquiry]
   ---

   본문 시작...
   ```

3. `categories`에는 다음 중 하나 이상을 넣습니다:
   - `purchase_inquiry` — 구매 의사
   - `pricing_question` — 가격 문의
   - `partnership` — 파트너십 제안
   - `support` — 기술/사용 문의
   - `recruiting` — 채용 문의
   - `other` — 기타
   - `all` — 모든 분류에서 항상 참조 (회사 개요 같은 공통 문서용)
4. `categories`를 생략하면 `[all]`과 동일하게 취급됩니다.
5. **변경 후 BE 재시작**하면 다음 호출부터 반영됩니다.

### 작성 팁

- 파일을 작게 쪼개세요 (`스타터플랜.md`, `엔터프라이즈.md` 식).
- 톤·금지어 같은 규칙은 [company_rules/](../company_rules/)에 두세요.
- 가격은 적되, "답장에 직접 인용하지 말 것" 같은 가이드도 함께 적어두면 LLM이 미팅 제안으로 자연스럽게 연결합니다.
- 더 자세한 작성 규칙은 `knowledge_base/README.md` 참고.

## 리포트 확인

### 자동 리포트

- **일간**: 매일 18:00 (n8n 스케줄) → Slack 채널 + 이메일
- **주간**: 매주 토요일 09:00 → Slack 채널 + 이메일

### 수동 리포트 생성

```powershell
curl -X POST http://127.0.0.1:8000/run/report?kind=daily `
  -H "X-Internal-Token: <토큰>"
```

### 리포트 파일 위치

생성된 리포트는 `data/reports/` 폴더에 마크다운 파일로도 저장됩니다:
- `data/reports/2026-05-15-daily.md`
- `data/reports/2026-05-10-weekly.md`

## 서버 관리

### 서버 시작

```
scripts\run.bat
```

브라우저에서 `http://127.0.0.1:8000/healthz`로 접속하여 서버 상태를 확인할 수 있습니다.

### 헬스체크

시스템의 모든 연결 상태를 확인합니다:

```powershell
.venv\Scripts\activate
python -m src.cli healthcheck
```

각 검사 항목:
- `db_connectivity` — DB 연결 상태
- `claude_cli_token` — Claude CLI 인증 상태
- `hubspot_token` — HubSpot API 토큰 유효성
- `smtp_login` — SMTP 메일 서버 연결
- `disk_space` — 디스크 여유 공간

### 서버 중지

`run.bat` 실행 중인 창에서 `Ctrl+C`를 누르면 서버가 종료됩니다.

## n8n 워크플로

n8n은 자동화 스케줄러입니다. 로컬에서 `npx n8n`으로 실행 후 `n8n_workflows/` 폴더의 JSON 파일을 import합니다.

| 워크플로 | 설명 |
|---|---|
| 01_inbound_webhook | HubSpot 인바운드 이벤트 수신 |
| 02_outbound_cron | 매일 09:00 아웃바운드 실행 |
| 03_reply_check | 매시간 답장 확인 |
| 04_approval_card | 승인 카드 발송 |
| 05_daily_report | 매일 18:00 일간 리포트 |
| 06_weekly_report | 매주 토요일 주간 리포트 |
| 07_healthcheck | 15분마다 시스템 상태 점검 |
