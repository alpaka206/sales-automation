# PERSO 더빙 FAQ·응대 가이드

AI 더빙(Dubbing) 관련 고객 문의에 대응할 때 참고하는 사실/정책 레퍼런스와 한국어 응답 템플릿. 응답 예시의 `유저이름`/`고객명` 플레이스홀더는 실제 고객명으로 치환해 사용.

## 지원 언어

핵심 사실/정책:
- PERSO AI 더빙은 **총 34개 언어**에 대해 번역 및 음성 클로닝을 지원한다.
- 지원 언어 목록: 카자흐어(신규), 태국어, 그리스어, 노르웨이어, 네덜란드어, 덴마크어, 독일어, 루마니아어, 러시아어, 말레이어, 베트남어, 불가리아어, 브라질 포르투갈어, 스웨덴어, 스페인어, 슬로바키아어, 아랍어, 영어, 우크라이나어, 이탈리아어, 인도네시아어, 일본어, 중국어, 체코어, 크로아티아어, 타밀어, 터키어, 필리핀어, 핀란드어, 프랑스어, 폴란드어, 한국어, 헝가리어, 힌디어.
- **핵심 규칙**: 원본 언어는 지원 언어가 아니어도 무방하다. **번역(타겟) 언어가 지원 언어이면 번역·더빙 가능**, 타겟 언어가 미지원이면 불가능.
- 즉 미지원 언어 원본 영상도 지원 34개 언어로 번역·더빙 가능하며, 이때 보이스 클로닝 및 화자 분리 기능도 그대로 적용된다.
- 미지원 언어 원본에 (예: 한국어) SRT 자막 파일을 업로드하면 그 SRT 기반으로 지원 언어 번역·더빙이 가능하나, 원본 음성과 자막 언어가 달라 품질이 완벽히 보장되기는 어려울 수 있다.
- 무료 체험(최대 1분 영상) 제공 — 직접 테스트 권장.

> 운영자 참고: 위 명명된 목록(34개)은 CS 확인 기준 **주요 지원 언어**입니다. 한편 [perso.ai/pricing](https://perso.ai/pricing)에는 **99개 이상 언어**로 안내됩니다(지속 확대 중). 정확한 최신 수치/목록은 perso.ai 기준이며, 고객에게 "수십 개 언어 지원, 지속 확대 중"으로 안내하고 구체 목록이 필요하면 위 주요 언어를 제시하세요. (노션 구버전엔 "33개"도 혼재)

## SRT 자막 기능

핵심 사실/정책:
- 원본 소스와 함께 SRT 파일을 입력하면 더 안정적인 번역·더빙 결과를 기대할 수 있다. AI가 음성을 처음부터 전사하는 대신 완성된 자막 기준으로 작업하므로 전문 용어·고유명사가 많은 콘텐츠에서 특히 안정적.
- 편집 페이지에서 **캡션 토글을 ON** 하면 번역된 자막을 화면에서 바로 확인 가능. 번역된 SRT 파일을 내려받아 외부 편집 툴에서 활용 가능.
- **제약**: SRT 파일을 첨부해 타임라인에 맞춰 자동으로 영상 자막이 입혀지는 방식은 지원하지 않는다.
- **SRT 업로드 기능은 Enterprise 플랜 전용**이다. 사용을 원하면 플랜 업그레이드(또는 Enterprise 상담) 안내.

응답 예시:
```
안녕하세요 😊 유저이름 고객님!
Perso AI를 이용해주셔서 감사합니다.
문의 주신 SRT 파일 기능에 대해 안내드립니다.
현재 Perso AI에서는 사용자가 업로드한 원본 SRT 파일을 기반으로 번역과 더빙을 자동 생성하실 수 있으며, 편집 페이지에서 캡션 토글을 ON 하시면 번역된 자막을 화면에서 바로 확인하실 수 있습니다.
다만, SRT 파일을 첨부하면 타임라인에 맞춰 자동으로 영상 자막이 생성되는 방식은 지원되지 않고 있습니다. 대신 번역된 SRT 파일을 내려받아 외부 편집 툴에서 활용하실 수 있습니다.
추가로, SRT 업로드 기능은 Enterprise 플랜 전용 기능으로 제공되므로 해당 기능을 이용하시려면 플랜 업그레이드를 권장드립니다.
Enterprise 상담을 원하실 경우에도 언제든지 편하게 문의 주시면 빠르게 안내 도와드리겠습니다 :)
추가로 궁금하신 점이 있으시면 언제든지 편하게 문의 주세요!
감사합니다.
Perso AI 드림
```

## 음성/목소리 복제

핵심 사실/정책:
- **음성 복제(Voice replication)**: AI가 원본 영상의 목소리를 학습하여, 다른 언어로 변환 시에도 동일한 목소리와 톤을 유지.
- **음성 분리 & 번역**: 영상의 음성을 분리하여 영어·스페인어·중국어·불어 등 다양한 언어로 자동 번역.
- 목소리 복제는 AI가 내부 데이터베이스에서 가장 유사한 목소리를 자동으로 매칭하므로, 간혹 사람이 기대한 것과 다르게 나올 수 있다. 정확도는 지속 개선 중.
- 매칭 오류 문의 시: 편집 화면 우측 하단의 **'Share URL'**을 받아 확인 가능.

응답 예시 (음성 특성 안내):
```
안녕하세요, 고객명 님
Perso AI Dubbing에 관심 가지고 문의 주셔서 감사합니다.
AI 더빙의 음성 관련 특성으로는 음성 복제 및 분리 기술이 있습니다.
음성 복제: AI가 원본 영상의 목소리를 학습하여, 다른 언어로 변환 시에도 동일한 목소리와 톤을 유지합니다.
음성 분리 & 번역: 영상의 음성을 분리하여, 다양한 언어로 자동 번역할 수 있습니다.
이용에 참고 부탁 드립니다. 감사합니다.
Perso AI
```

```
영상 편집 화면의 오른쪽 하단에 있는 'Share URL'을 클릭하여 보내주시면 확인해보겠습니다.
```

## 립싱크 — 생성 방식 (UI)

핵심 사실/정책 (2026-04-14 업데이트):
- 기존: 번역 설정창에서 '립싱크 생성' 체크박스로 립싱크 여부를 선택.
- 변경 후: 새 프로젝트 생성 버튼이 **'더빙 생성하기'와 '립 더빙 생성하기'로 분리**되었고, 번역 설정창의 '립싱크 생성하기' 체크박스는 제거됨.
- 립 더빙 진입 경로: 홈 상단 '립 더빙' 버튼, 또는 더빙/립 더빙 메뉴의 '새 프로젝트 → 립 더빙' 선택 시 립 더빙 프로젝트 생성.

## 립싱크 — 입모양이 움직이지 않는 문제

핵심 사실/정책:
- 립싱크 기술은 원본 영상에서 움직이는 인물의 입모양을 학습한 뒤 다른 언어로 자연스럽게 변환하는 방식이다.
- 원본 영상 자체에 입모양 움직임이 없고 음성이 별도 편집·삽입된 형태라면, 학습할 데이터가 부족해 결과물에서도 입모양이 움직이지 않는다. 이는 기술적 오류가 아닌 정상 동작.
- 이 경우 차감된 크레딧 복구 및 다른 영상으로의 재시도 제안 가능.

> 운영자 참고: 해당 케이스 발생 시 더빙 담당자(엔진팀) 확인 필요. 크레딧 복구 여부는 내부 확인 후 안내.

응답 예시:
```
안녕하세요, Perso AI 문의지원팀입니다.
문의하신 더빙 영상의 입모양 관련 건을 내부 개발팀과 함께 확인해보았습니다.
확인 결과, 업로드하신 원본 영상에서 인물의 입모양이 움직이지 않고, 음성이 별도로 편집되어 삽입된 형태로 제작된 영상이었습니다.
저희 립싱크 기술은 원본 영상에서 움직이는 인물의 입모양을 학습한 후, 다른 언어로 자연스럽게 변환하는 방식으로 작동하는데요. 원본 영상 자체에 입모양의 움직임이 없었기 때문에, 학습할 데이터가 부족하여 결과물에서도 입모양이 움직이지 않는 것입니다.
이건 기술적 오류가 아닌 정상적인 동작이지만, 이번 영상의 특성상 원하시는 결과물을 얻으시기 어려웠을 것 같아서 차감된 크레딧을 복구해드리려고 합니다.
다른 영상으로 재시도해보시면 더 좋은 결과물을 얻으실 수 있을 것 같은데 어떠신가요?
그 외 서비스 이용 중 궁금한 점이 있으시면 언제든 편하게 문의 주세요.
감사합니다. 🙏
Perso AI 문의지원팀 드림
```

## 더빙 영상 처리 속도

핵심 사실/정책:
- 처리 시간은 영상의 길이, 해상도, 복잡도에 따라 달라진다.
- 일반 가이드라인:
  - 일반 더빙: 영상 1분당 약 3~5분 소요.
  - 립싱크 활성화: 영상 1분당 10분 이상 소요.
  - 영상이 길거나 해상도가 높을수록 추가 시간 필요.
  - 네트워크·서버 사정에 따라 더 소요될 수 있음.

응답 예시:
```
안녕하세요, 고객명 님.
Perso AI를 통해 문의해 주셔서 감사합니다.
영상 처리 시간은 각 영상의 길이, 해상도, 복잡도에 따라 달라질 수 있습니다.
일반적인 가이드라인:
- 일반 더빙의 경우 영상 1분당 약 3~5분이 소요될 수 있습니다.
- 립싱크가 활성화된 경우 영상 1분당 10분 이상 소요될 수 있습니다.
- 영상이 길거나 해상도가 높을수록 추가 시간이 필요할 수 있습니다.
```

## 처리 모드 — 고속(Fast/RED)·저속(Low/GREEN)

핵심 사실/정책:
- **Fast Speed(고속, RED)**: Creator 플랜 이상에 매월 일정량의 고속 생성 시간이 제공된다. 이 시간 동안은 최고 속도로 생성. 고속 모드는 동시에 1개까지만 처리 가능.
- 할당된 Fast Speed 시간을 모두 소진하면 자동으로 **Low Speed(저속, GREEN) 모드**로 전환된다. 저속 모드에서도 생성은 중단 없이 계속되나 속도가 느려진다.
- 저속 모드 제약: **생성당 최대 5분**, 큐잉(queueing) 없음, 동시 처리 없음.
- 매월 대량의 고속 생성이 필요하거나 전체 워크플로우를 고속으로 돌려야 하면 Enterprise 플랜(맞춤 리소스 할당) 안내.

### 저속 모드 버튼 위치 (UI, 2026-04-14 업데이트)

- 기존: 번역 설정창 → 번역 언어 선택 후 생성하기 클릭 시 저속/고속 선택 팝업 노출.
- 변경 후: **번역 설정창 → Advanced 탭 → 하단 '저속모드로 생성하기' 버튼**을 눌러야 이용 가능. ('저속모드 어디 있나요?' 문의 시 안내.)

## API 문의

핵심 사실/정책:
- API는 **모든 플랜에서 사용 가능**하며, 워크스페이스 좌측 메뉴의 **Developers** 메뉴에서 이용한다. API 사용 시 더빙 크레딧(Fast Speed 분)이 동일하게 차감된다.
- API는 **기본 스페이스(Main 스페이스)**에서만 사용 가능. 좌측 상단 '스페이스 배너'에서 'Main'으로 표시된 것이 기본 스페이스.
- 저속 모드(GREEN)는 크레딧 차감 없이 사용 가능. 단, 고속 모드(RED)는 동시에 1개까지만.
- 저속 모드(GREEN) 기준 API 요청 1회당 최대 오디오 길이는 **5분**.
- API는 파일을 직접 반환하지 않고 파일 경로(path)를 응답한다. 다운로드는 (1) `/video-translator/api/v1/projects/{projectSeq}/spaces/{spaceSeq}/download` 엔드포인트로 경로 조회 후, (2) 경로 앞에 `https://portal-media.perso.ai` 를 붙여 최종 URL 구성. 문서: https://developers.perso.ai/docs/file#download

## 스펠링 발화 문제 (약어/고유명사가 철자로 읽힘)

핵심 사실/정책:
- "NATO", "Shahed" 같은 약어·고유명사가 자연스럽게 발음되지 않고 철자대로 읽히는 현상은 **타겟 언어가 한국어일 때** 발생한다.
- LLM 무작위성 때문이 아니라, 최근 기본값이 된 *"Natural Korean Intonation"* 모델의 알려진 한계다.
- **임시 우회**: Script Editing 기능에서 한국어 타겟 텍스트에 의도한 발음을 한국어로 직접 표기 (예: "NATO" 대신 "나토" 입력).
- 응대 전 타겟 언어가 한국어인지 먼저 확인. 한국어가 아니면 다른 케이스일 수 있으므로 재조사 안내.

> 운영자 참고: 엔진팀에서 최우선(top priority) 개선 과제로 등록됨. 일정 확정 시 별도 공유.
