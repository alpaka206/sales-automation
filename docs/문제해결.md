# 문제 해결

자주 발생하는 문제와 해결 방법입니다.

---

## 서버가 안 뜸

### 증상
`scripts\run.bat`을 실행했는데 서버가 시작되지 않거나 즉시 종료됨

### 원인 1: .venv가 없음
```
[오류] .venv가 없습니다
```
**해결:** `scripts\setup.bat`을 먼저 실행하세요.

### 원인 2: 포트 충돌
```
ERROR: [Errno 10048] Only one usage of each socket address is permitted
```
**해결:** 이미 8000번 포트를 사용하는 프로그램이 있습니다.
```powershell
# 8000번 포트를 사용하는 프로세스 찾기
netstat -ano | findstr :8000
# 해당 프로세스 종료 (PID를 위에서 확인)
taskkill /PID <PID번호> /F
```
또는 `.env`에서 `APP_PORT=8001`로 변경하세요.

### 원인 3: 의존성 미설치
```
ModuleNotFoundError: No module named 'fastapi'
```
**해결:**
```powershell
.venv\Scripts\activate
pip install -e ".[dev]"
```

## doctor가 FAIL 표시

### 증상
`python -m src.cli doctor` 실행 시 `[XX]` 항목이 있음

### Database FAIL
```
[XX] Database              run: python scripts/init_db.py
```
**해결:**
```powershell
.venv\Scripts\activate
python scripts/init_db.py
```

### Claude CLI FAIL
```
[XX] Claude CLI            'claude' not found on PATH
```
**해결:**
1. Claude Code가 설치되어 있는지 확인
2. 터미널에서 `claude --version` 실행 가능한지 확인
3. 안 되면 Claude Code를 재설치하거나, `LLM_PROVIDER=anthropic_api`로 변경

### Anthropic API Key FAIL
```
[XX] Anthropic API Key     ANTHROPIC_API_KEY empty
```
**해결:** `.env`에 `ANTHROPIC_API_KEY=sk-ant-...` 값을 입력하세요.
발급 방법은 [설정.md](설정.md#anthropic_api_key)를 참고하세요.

### SMTP FAIL
```
[XX] SMTP                  EMAIL_PROVIDER=smtp but credentials missing
```
**해결:** `.env`에서 `SMTP_USERNAME`과 `SMTP_PASSWORD`를 설정하세요.
Gmail 사용 시 앱 비밀번호가 필요합니다. [설정.md](설정.md#gmail-app-password-발급-방법-smtp용)를 참고하세요.

## 이메일이 안 보내짐

### 증상
승인 버튼을 눌렀는데 이메일이 도착하지 않음

### 원인 1: SMTP 인증 실패
**확인:**
```powershell
.venv\Scripts\activate
python -m src.cli healthcheck
```
`smtp_login` 항목이 FAIL이면 `.env`의 SMTP 설정을 확인하세요.

### 원인 2: Gmail 앱 비밀번호 오류
Gmail은 일반 비밀번호로 SMTP 로그인이 불가능합니다.
- 2단계 인증이 활성화되어 있는지 확인
- 앱 비밀번호를 재발급 받아 입력

### 원인 3: HubSpot 이메일 권한 부족
`EMAIL_PROVIDER=hubspot`인 경우 HubSpot Private App에 이메일 관련 스코프가 필요합니다.

**해결:** HubSpot 설정 → Private Apps → 스코프에서 `sales-email-read` 권한 확인

## Slack 알림이 안 옴

### 증상
승인 카드나 리포트가 Slack에 도착하지 않음

### 원인 1: 봇 토큰이 잘못됨
**확인:**
```powershell
.venv\Scripts\activate
python -c "from src.common.config import settings; print('Token set:', bool(settings.SLACK_BOT_TOKEN))"
```

### 원인 2: 채널 ID가 잘못됨
Slack 채널 ID는 `C`로 시작하는 문자열입니다 (예: `C0123456789`).
채널 이름이 아닌 **ID**를 입력해야 합니다.

**확인 방법:** Slack에서 채널 이름 우클릭 → 채널 세부정보 → 하단의 채널 ID

### 원인 3: 봇이 채널에 추가되지 않음
Slack 봇이 해당 채널의 멤버여야 합니다.
- 채널에서 `/invite @봇이름` 입력
- 또는 봇에 `chat:write.public` 스코프를 추가

## Teams 알림이 안 옴

### 증상
`APPROVAL_CHANNEL=teams`로 설정했는데 카드가 안 옴

### 원인 1: Webhook URL이 만료됨
Teams Incoming Webhook URL은 오래되면 비활성화될 수 있습니다.

**해결:** Teams 채널 설정에서 웹훅을 재생성하세요.

### 원인 2: URL 형식 오류
URL이 `https://`로 시작하고 `webhook.office.com`을 포함해야 합니다.

## 백그라운드 워커가 동작 안 함

### 증상
인바운드 폴링 또는 발송 워커가 안 도는 것 같음 (로그에 `Inbound poller started` 또는 `Send worker started` 보이지 않음)

### 원인 1: 환경변수 미활성화
`.env` 의 다음 값이 `true` 인지 확인:
```
INBOUND_POLL_ENABLED=true
SEND_WORKER_ENABLED=true
```
변경 후 BE 재시작 (`scripts\run.bat`).

### 원인 2: 서버가 꺼져 있음
백그라운드 워커는 FastAPI 프로세스 안에서 돌기 때문에 BE 가 살아있어야 합니다.

**확인:**
```powershell
curl http://127.0.0.1:8000/healthz
```
`{"ok":true}` 가 나오면 서버 정상.

## 헬스체크 FAIL

### 증상
`python -m src.cli healthcheck`에서 `[XX]` 항목 발생

### claude_cli_token FAIL
Claude Code CLI 세션이 만료되었습니다.
```powershell
claude login
```

### hubspot_token FAIL
HubSpot 토큰이 잘못되었거나 만료되었습니다.
HubSpot 설정에서 Private App 토큰을 확인하세요.

### db_connectivity FAIL
DB 파일이 손상되었거나 경로가 잘못되었습니다.
```powershell
# DB 재초기화 (기존 데이터 유지, 테이블만 추가)
.venv\Scripts\activate
python scripts/init_db.py
```

### disk_space WARN
`data/` 폴더가 있는 드라이브의 여유 공간이 500MB 미만입니다.
불필요한 파일을 삭제하여 공간을 확보하세요.
