# 소스별 톤 & 어프로치

> LLM 은 메일 작성 시 **상대방의 소스 (어디서 발굴됐는지)** 에 따라 톤·구조·call-to-action 을 다르게 적용해야 합니다. 아래 가이드는 `source` 변수 (youtube / linkedin_csv / linkedin_comments / google_search / job_board / manual_csv) 와 도메인 분석 결과를 함께 고려해서 매칭하세요.

---

## 🎬 YouTube 크리에이터

### 컨텍스트

- 발굴 채널: YouTube Data API 또는 댓글 스크래핑
- 상대방은 **개인 또는 소규모 팀**. 격식보다 **간결·존중·구체성** 이 중요
- 이미 영상 운영 중이므로 다국어 더빙·자막 워크플로우의 **반복 작업 부담** 을 공감하면 효과적

### 톤

- 격식은 유지하되, **딱딱하지 않게**. "~합니다" 어조이되 문장 사이 호흡을 약간 더 자연스럽게.
- 첫 문장에서 상대 **채널·콘텐츠 주제** 를 1줄로 언급 (구독자 수·조회수 절대 언급 X — 부담스러움)
- 절대 "구독자 N만의 인기 채널" 같은 표현 X — 진부함 + 영업 냄새

### 구조 (3단락)

1. **인사 + 채널 주제 공감 1문장** ("다국어 자막 댓글이 많은 걸 보고 연락드립니다" 식)
2. **PERSO Dubbing 의 어떤 점이 도움될지 1문장** + 작업 시간 절약 효과 1줄
3. **CTA**: "이번 주 화/수 오후 중 15분 통화" 또는 "샘플 영상 1편 무료 다국어 더빙 데모"

### 금지

- "협업 제안", "광고 문의" 같은 무거운 단어 (상대가 광고 권유로 오해)
- 채널 분석 데이터 (구독자/조회수) 인용 → 사찰 느낌
- 영상 제목·내용 잘못 인용하면 즉시 신뢰 상실 → 모르면 일반화

## 💼 LinkedIn 프로페셔널

### 컨텍스트

- 발굴 채널: LinkedIn CSV (Sales Navigator export) 또는 댓글 스크래핑
- 상대방은 **직장인·의사결정자**. 보통 마케팅·콘텐츠·로컬라이제이션 직무
- LinkedIn 이라는 **공개 비즈니스 네트워크 컨텍스트** 가 있어 콜드 메일에 비교적 관대

### 톤

- 가장 **격식** 있는 톤. "~드립니다", "~로 인사드립니다"
- **상대 직무·회사** 명시. "{회사명}의 {직무} 로 활동하시는 모습 보고 연락드립니다"
- **영문 메일 가능성 검토** — 회사가 글로벌이면 영문 우선

### 구조 (3~4단락)

1. **인사 + 발견 경로 1줄** ("LinkedIn 의 {업계} 관련 게시물 보고 연락드립니다")
2. **회사의 글로벌 콘텐츠 운영 시나리오 가설** 1줄 + PERSO 가 그 시나리오에서 어떤 가치를 더하는지
3. **유사 산업 도입 사례 일반화** ("국내 대기업 콘텐츠팀에서 다국어 워크플로우 자동화 사례 있음")
4. **CTA**: 30분 미팅 제안 (다음 주 가능 일자 2개 제시)

### 금지

- "LinkedIn 에서 프로필 보고" 직접 언급 → 스토킹 느낌. "관련 게시물" 정도로 우회.
- 1차 인맥 추측 ("저희 회사 OO 와 아시는 사이로 알고 있어") — 사실 확인 안 된 추측은 절대 금지
- 단일 메일에 3개 이상 CTA → 의사결정자는 1개 CTA 만 클릭

## ⛪ 종교 단체

### 컨텍스트

- 발굴 채널: Google Search (`종교`, `교회`, `사찰`, `학회` 키워드)
- 상대방은 **종교 법인** — 영상 콘텐츠·다국어 설교·해외 선교 운영
- **민감 카테고리**: 일반 종교 OK, **사이비 의심**은 별도 처리

### 분기

- **일반 종교 (개신교 주류·천주교·불교·이슬람·유대교 등 공인 종교법인)**: 일반 콜드 메일 진행 가능
- **사이비 의심 시그널** (도메인 분석에서 "controversial", "cult", 또는 신천지·JMS·통일교·구원파 등 명백 시그널): **자동 발송 큐에서 제외 + 운영자 수동 검토 라벨**

### 톤 (일반 종교 한정)

- 가장 **존중·차분** 한 톤. 영업적 단어 (ROI·효율·생산성) 사용 X
- "사역", "전파", "복음", "신도", "성도" 같은 단어 → 우리가 외부인이므로 **사용 X**. 대신 "콘텐츠를 더 많은 분께 전달", "다국어 자막"
- 종교적 슬로건·인사말 시도 X → 외부인이 흉내내면 오히려 결례

### 구조 (3단락, 가장 짧게)

1. **인사 + 단체명 + "다국어 콘텐츠 제작 관련 짧게 안내드리고 싶어 연락드립니다"**
2. **영상·강연 콘텐츠를 다국어로 확장하는 솔루션 소개 1문장** + 무료 데모 영상 1편 제안
3. **CTA**: "회신 주시면 자료를 보내드리겠습니다." (미팅 강요 X)

### 금지

- 신앙·교리 평가 절대 금지 ("좋은 사역을 하시는 것을 보고...")
- 종교 행사·일정 (예배·법회) 시간대 발송 회피 (일요일 오전·금요일 저녁 등은 country_send_windows 에 avoid_hours 로 등록 권장)
- 단체 비교·경쟁 언급 X

### 발송 정책

- 사이비 의심 시그널이 하나라도 매칭되면 → **`status=pending_manual_review`** 로 강제 라벨, 자동 발송 큐 진입 X
- 메일 본문에 unsubscribe 링크 + "본 메일은 단체 공식 채널을 통해 확인된 정보 기반" 명시

## 🎓 대학·학회·연구기관

### 컨텍스트

- 발굴 채널: Google Search (`대학`, `학회`, `연구소`, `심포지엄`, `컨퍼런스`)
- 상대방은 **교수·연구원·행정직원**. 결제 권한 X — 단지 추천·도입 검토 가능
- 영상 콘텐츠는 **강의 녹화·학회 발표 다국어화** 가 주 시나리오

### 톤

- 가장 **격식·간결**. "~드립니다", "~로 안내드립니다"
- 학술적 단어 일부 차용 가능 — "다국어 접근성", "글로벌 학술 교류"
- **수업·연구 시간 침범 안 한다는 신호** — "5분만 시간 내주시면..." 같은 작은 약속

### 구조 (3단락)

1. **인사 + 학과·연구 분야 1줄 언급** ("{학과} 글로벌 강의 운영 관련 자료 안내드리고자 연락드립니다")
2. **강의·발표 다국어 자막·더빙 자동화 가치** 1문장 + "무료 평가판 1주" 제안
3. **CTA**: "관심 있으시면 회신 부탁드립니다. 학교 측 도입 절차에 맞춰 자료 준비하겠습니다."

### 금지

- 가격 직접 언급 X (학교 회계는 별도 절차)
- 학회·논문 인용 시도 X (틀리면 즉시 신뢰 상실)
- "당신의 연구가 글로벌 임팩트를 가진다" 같은 추켜세움 → 식상함

## 🏥 채용 페이지 발굴 (병원·마케팅·성형외과 등)

### 컨텍스트

- 발굴 채널: 잡코리아·사람인의 채용 공고에서 **회사 도메인·채용 담당자 메일** 추출
- 상대방은 **인사담당자 또는 마케팅 담당자**. 채용 공고를 올린 상태 = 성장·확장 시그널
- 주 시나리오: 광고 영상·시술 안내 영상 다국어 (외국인 환자 유치)

### 톤

- **격식 + 비즈니스 직접성**. "{회사명}이 콘텐츠 마케팅 채용을 진행 중인 걸 확인했다" 정도 언급은 OK (공개 정보)
- 빠른 ROI 메시지 우호적 — "다국어 영상 제작 외주 대비 N분의 1 시간"
- 의료법·광고법 민감 — "효과·증상·치료 보장" 같은 약속 X

### 구조 (3단락)

1. **인사 + "{회사명}이 마케팅·콘텐츠 인력 채용 중인 걸 확인하고 연락드립니다"**
2. **외국인 환자 유치 / 글로벌 광고 영상 다국어 워크플로우** 가치 1문장
3. **CTA**: "15분 통화로 도입 효과 시뮬레이션 보여드릴 수 있습니다. 이번 주 화/목 오후 중 가능하신 시간 알려주세요."

### 금지

- 의료 광고법 위반 시그널 ("효과 보장", "최저가") 작성 절대 금지
- 환자 데이터·진료 결과 인용 X
- 특정 시술·진료 과목 언급 X (의료법 광고 심의 대상)

## 🏢 엔터프라이즈 (대기업·B2B 도메인)

### 컨텍스트

- 발굴 채널: manual_csv 또는 LinkedIn / 도메인 분석에서 `size_hint="enterprise"`
- 상대방은 **부장·팀장급 의사결정자 또는 실무 담당자**
- 도입 결정까지 다단계 (실무 검토 → 보안 검토 → 법무 → 구매)

### 톤

- **가장 격식 + 신중**. "~드립니다", "~로 인사드립니다"
- 첫 메일에서 가격·기능 디테일 X — 오직 **미팅 1개** 가 목표
- 케이스 스터디 일반화 OK ("유사 산업 글로벌 브랜드에서 도입 사례가 있음")

### 구조 (3~4단락)

1. **인사 + "{회사명}의 글로벌 콘텐츠 운영 관련 자료를 안내드리고자 연락드립니다"**
2. **PERSO AI 가 다국어 더빙·자막·라이브 통역 워크플로우를 자동화한다는 1문장**
3. **유사 산업 도입 사례 + NDA 검토 후 디테일 공유 가능** 1문장
4. **CTA**: 30분 미팅 (실무 담당자 + 의사결정자 동석 가능하면 좋음). 다음 주 가능 일자 2개 제시.

### 금지

- 첫 메일에 가격 명시 → 엔터프라이즈 트랙 자체 무효화
- 셀프서브 가입 URL 안내 X (Stripe 결제 페이지 직접 링크는 절대 금지)
- 약속 못 지킬 SLA·SSO·보안 인증 언급 (내부 확인 안 된 내용 X)

## 🆕 manual_csv (운영자가 직접 업로드)

### 컨텍스트

- 운영자가 미리 검토한 발굴 리스트 — 다른 소스보다 신뢰도 높음
- CSV 에 메모(`note`) 컬럼이 있으면 그 컨텍스트 활용

### 톤

- 운영자 메모를 따름. 메모 없으면 도메인 분석 + 회사 규모로 위 6개 카테고리 중 매칭
- 기본값은 **LinkedIn 프로페셔널** 톤 (격식)

## 공통 적용 규칙 (모든 소스)

1. **첫 메일 길이**: 250자 이내 권장. 길면 무조건 짧게.
2. **링크는 최대 1개** — 디모 URL 또는 회사 홈페이지 중 1개만.
3. **첨부 X** — PDF·이미지 첨부는 스팸 필터 위험.
4. **답장 검토 모드**: 답장 메일은 위 6개 카테고리 무관, [[01_tone.md]] 의 기본 답장 규칙 따름.
5. **language 변수 우선**: `language=en` 이면 영문, `language=ja` 이면 일문. 톤 가이드 의미는 유지하되 문장 구조는 해당 언어 비즈니스 관행 따름.
6. **언어 미스매치 시그널**: 한국 도메인이지만 영문 사이트 운영 → 영문 메일 우선 검토 (의사결정자가 영문 글로벌 팀일 가능성).
