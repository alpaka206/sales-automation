# 환불 정책

## 환불 가능 조건

- 결제일로부터 **30일 이내**
- 약관 위반·부정 사용이 없을 것
- 시스템 오류로 인한 결제 실패: **100% 환불**
- 서비스 중단으로 인한 미사용 분: **별도 보상 (개별 안내)**

## 환불 계산 공식

```
환불액 = 결제 금액 − (PG 수수료 + 일일 사용료 × 사용 일수)

일일 사용료 = (정상가 연간 요금 ÷ 12개월) ÷ 해당 월 일수
```

### 적용 규칙

| 항목 | 규칙 |
|------|------|
| 계산 기준 | 할인가가 아닌 **정상가** 기준으로 사용량 산정 |
| 소수점 처리 | 둘째 자리에서 반올림 |
| PG 수수료 | Stripe 수수료 vs 결제액의 6% 중 **높은 쪽** 적용 |
| 환불 불가 | 결제일 30일 초과 / 약관 위반 / 부정 사용 |

### 계산 예시

> 연간 Creator 플랜, 결제액 $348 (정상가 $468, 할인 26%)
> 결제일 8/19, 환불 요청 8/20, 사용 일수 2일

1. 정상가 기준 월 요금: $468 ÷ 12 = $39
2. 일일 사용료: $39 ÷ 31일 ≈ $1.3
3. 사용량 차감: $1.3 × 2일 = $2.6
4. PG 수수료: $348 × 6% = $20.88 vs Stripe $21.00 → **$21.00 적용**
5. **환불액: $348 − ($21.00 + $2.6) = $324.40**

## 처리 플로우

1. 결제 정보 + 사용 이력 확인
2. 환불액 계산 (사용량 기반)
3. 고객에게 환불액 안내 + 동의 확인
4. 환불 처리 (영업일 **3~5일**)
5. Stripe 구독 취소
6. 백오피스 크레딧 취소
7. 환불 완료 알림

## 답장 시 어조

- 환불 문의 → 먼저 **결제일·플랜·사용 시작 여부** 3가지 확인. 이후 정확한 환불액은 영업일 1일 내 별도 안내 약속.
- "공식 환불 정책 링크" 를 메일에 직접 첨부하지 말 것 (퍼블릭 URL 정해진 뒤에만 안내). 내부 처리 절차임을 명시.
- 30일 초과 환불 요청 → 정중히 거절하되 **크레딧 연장·플랜 변경** 등 대안을 1개 제시.
