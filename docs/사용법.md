# 운영 사용법

## 매일 보는 화면

- `/`: 오늘 들어온 문의, 작성 중 초안, 검토 대기, 발송 실패를 확인합니다.
- `/messages`: 문의 원문·번역·같은 고객 이력을 보며 답변을 수정하고 발송합니다.
- `/customers`: Negotiation·서비스 이용 고객의 상태와 다음 액션을 관리합니다.
- `/operations`: 답장 누락 가능성, 14일 이상 미접촉, 60일 이내 갱신, 플랜 후보를 확인합니다.
- `/email-templates`: 접수 확인 문구와 HTML 서명을 편집합니다.
- `/tools/quote-calculator`: 플랜 견적을 계산합니다.

## 신규 문의

웹훅이 우선이고 10분 폴러가 누락을 보완합니다. `New` 단계의 첫 문의가 저장되면 접수 확인 메일이 즉시 나갑니다. 상세 초안이 완성되어 `pending_approval`이 된 뒤에만 Slack 알림이 옵니다.

검토 화면에서 본문·제목·서명을 수정하고, 외국어 문의는 번역 결과를 확인한 뒤 `검토 완료 · 발송`을 누릅니다. 발송은 SMTP로 이루어지고 성공 후 HubSpot 활동과 티켓 단계가 갱신됩니다.

## 고객 히스토리

고객 상세에서 HubSpot 동기화 버튼을 누르면 현재 연락처, 최근 이메일, Deal, 메모를 가져옵니다. 온라인 미팅·카카오·전화·WhatsApp·계약서처럼 자동 커넥터가 없는 기록은 `기록 추가`로 입력하고 관련 문서 URL을 붙입니다.

미팅 기록은 파이프라인을 `Negotiation`으로, 활성 계약 등록은 고객을 `서비스 이용중 / Active`로 이동합니다. 자동 값이 틀릴 수 있으므로 고객 상태 폼에서 언제든 수동 수정할 수 있습니다.

## 계약과 결제

계약 상태, 금액, 통화, 포트원·Stripe·계좌이체, 계약일, 결제 예정일, 실제 입금일, 만료일, 언어쌍, 단가, 견적서·Invoice·결제 URL을 저장합니다. 저장된 계약은 Flex 품의용 텍스트로 복사할 수 있습니다.
