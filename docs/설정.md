# 설정

실제 값은 Git에 올리지 않는 `.env`에 넣고, 키 목록은 `.env.example`을 기준으로 합니다.

## 필수

- `INTERNAL_API_TOKEN`: 내부 JSON API 보호
- `GOOGLE_CREDENTIALS_JSON`, `GOOGLE_CLOUD_PROJECT`: Vertex AI
- `HUBSPOT_PRIVATE_APP_TOKEN`: 연락처·티켓·활동 읽기/쓰기
- `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL`: 실제 이메일 발송

`EMAIL_PROVIDER=smtp`를 사용합니다. HubSpot CRM 이메일 API는 실제 배달 수단이 아니라 전송 성공 후 타임라인 기록 용도입니다.

## 현재 개발자 HubSpot 계정

```env
HUBSPOT_TICKET_STAGE_NEW=1
HUBSPOT_TICKET_STAGE_AFTER_SEND=2
```

현재 계정의 `2`는 `Waiting on contact` 임시 단계입니다. 실제 계정에 `Meeting link sent`를 만든 뒤 해당 내부 ID로 교체합니다.

## 폴러와 워커

```env
INBOUND_POLL_ENABLED=true
INBOUND_POLL_INTERVAL_SECONDS=600
INBOUND_AUTO_ACK_ENABLED=true
SEND_WORKER_ENABLED=true
```

## Slack

기본값은 완전 비활성화입니다.

```env
SLACK_ENABLED=false
APPROVAL_CHANNEL=none
```

답변 초안이 준비된 순간에만 알림을 받으려면 토큰과 채널 ID를 설정한 뒤 두 값을 각각 `true`, `slack`으로 바꿉니다. 동일 초안은 DB의 `slack_notified_at`으로 한 번만 전송됩니다. 접수 확인 메일, 테스트, 정기 보고서는 승인 채널로 보내지지 않습니다. 정기 보고서는 `REPORT_SLACK_CHANNEL_ID`를 별도로 설정한 경우에만 보냅니다.

## WhatsApp

Meta 승인 템플릿·전화번호 ID·토큰을 준비한 뒤 `HUBSPOT_WHATSAPP_OPT_IN_PROPERTY`에 명시적 동의 속성명을 넣고 `WHATSAPP_ENABLED=true`로 전환합니다. Cloud API에는 번호 존재 여부만 미리 조회하는 기능이 없어, 승인 템플릿 발송 결과로 유효성을 판단합니다.
