# PERSO AI 요금제 (perso.ai/pricing 기준)

> **인바운드 가격 문의 응대 원칙**: 고객의 사용 사례에 맞는 플랜을 **실제 가격과 함께 추천**하세요. ("통화로만 안내"가 아니라 메일에서 바로 추천.) 아래 표의 값만 사용하고, 없는 숫자는 만들지 마세요. 대규모/엔터프라이즈 시그널일 때만 가격 대신 영업 미팅을 제안합니다. 연간 결제 가격은 26% 할인가 기준입니다.

## 셀프서브 플랜 (Stripe 결제)

| 플랜 | 가격 | 월 크레딧 | 영상 최대 길이 | 내보내기 | 대상 |
|------|------|----------|---------------|---------|------|
| **Free** | **$0** | 첫 생성 무료 | 1분 | 1080p HD | 처음 체험해보는 사용자 |
| **Starter** | **$6.99 / 월** (월간 결제만) | 900 | 5분 | 1080p HD | AI 콘텐츠 입문자·개인 |
| **Creator** | **$21 / 월** (연 $252, 26%↓ / 정가 $29) | 1,800 | 15분 | 1080p HD | 유튜버·크리에이터·소규모 팀 |
| **PRO** | **$73 / 월** (연 $876, 26%↓ / 정가 $99) | 6,000 | 30분 | **최대 4K** | 전문 콘텐츠 제작자·대량 사용 |
| **Enterprise** | **커스텀 (영업 문의)** | 커스텀 | 60분 | 4K | 대규모·전용 서버·커스텀 구성 |

- 크레딧은 **사용한 초(秒)만큼만 차감**(pay only for seconds used).
- Creator·PRO·Enterprise는 **슬로우모드 더빙 무제한**(크레딧 무소모). Starter/Free는 슬로우모드 더빙 가능하나 길이 제한.
- Booster(동시 처리/대기열): Free·Starter 동시 1·대기 1 / Creator 동시 1·대기 2 / PRO 동시 2·대기 3 / Enterprise 커스텀.
- 모든 플랜 공통: 무제한 재생성, 무제한 저장, **워터마크 없음**.

## 공통 핵심 기능 (전 플랜)

- **더빙**: 원본 음성 유지, 34개+ 언어
- **립싱크 더빙**: 입 모양 정밀 동기화
- **음성→텍스트(STT)**: 스크립트 + 요약 + 액션 아이템
- **오디오 분리**: 트랙 분리·믹싱
- **스크립트 편집**: 문장 단위 미세 조정
- **커스텀 용어집**, **SRT 업로드**(정확한 싱크), **팀 협업/공유 워크스페이스**

## 사용 사례별 추천 (인바운드 답장용)

- **처음 써보는 개인 / 짧은 영상** → **Free**로 체험 후, 더 필요하면 **Starter($6.99/월)**.
- **유튜버·크리에이터·1인~소규모** → **Creator($21/월, 연결제)** — 가장 가성비 좋은 기본 추천. 영상 15분·월 1,800 크레딧·슬로우모드 무제한.
- **전문 제작·대량·4K 필요** → **PRO($73/월)** — 월 6,000 크레딧·영상 30분·4K.
- **대규모 조직 / 전용 서버 / 커스텀 보안·구성 / 60분 영상** → **Enterprise** — 가격은 사용 환경에 따라 달라지므로 **영업 미팅** 제안.

## B2B / Enterprise 보충 (셀프서브 외)

> 계약 기반 B2B는 [[perso_business_plan]], 엔터프라이즈 워크플로우는 [[perso_enterprise_workflow]] 문서 참고. 대기업·다수 스페이스·계약서·맞춤 결제(포트원/계좌이체)가 필요한 경우 셀프서브 가격 대신 영업 트랙으로 안내.

## 응대 어조 요약

- 개인/크리에이터 시그널(개인 이메일·유튜브 채널·1인 운영) → 위 추천 플랜을 **가격과 함께** 안내 + 자가 가입 링크 안내 가능.
- 엔터프라이즈 시그널(대기업 도메인·다수 좌석/스페이스·커스텀 세팅·보안/계약 언급·대량) → 셀프서브 가격 나열 X, **Enterprise 권유 + 15분 통화 제안**.
- 환불/SSO/보안/계약 등 정책 질문은 즉답 대신 "내부 검토 후 영업일 1~2일 내 회신" 약속.
