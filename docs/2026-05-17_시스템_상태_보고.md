## 1. 이 시스템이 하는 일

### 📥 인바운드 (들어온 문의 자동 처리)

1. 고객이 HubSpot 으로 문의 보냄 (메일/폼/연락처 생성)
2. 시스템이 자동 감지 (10분마다 또는 실시간 알림)
3. AI 가 문의 내용 분석 → "구매 문의" / "가격 문의" / "파트너십" 등 분류 + 점수 매김
4. 회사 정책 문서(요금제, 환불 규정 등)를 자동 참고해서 한국어 답장 초안 작성
5. 운영자(우리)가 웹에서 초안 확인 → "보내기" 클릭
6. HubSpot 으로 답장 메일 발송 + 같이 **WhatsApp 도 자동 발송**(번호 있으면)
7. HubSpot 의 고객 상태를 "신규" → "미팅 제안 발송됨" 으로 자동 변경

### 📤 아웃바운드 (잠재 고객 자동 발굴)

1. 운영자가 웹에서 **"이런 사람들을 조사해와"** 자연어 입력
   - 예: "구독자 10만 명 이상 의료기기 유튜브 채널"
   - 예: "성형외과 마케팅 채용 공고 낸 회사들"
   - 예: "AI 학회에서 발표한 대학 교수들"
2. AI 가 입력을 이해해서 적절한 채널(YouTube / LinkedIn / Google / 채용 사이트)에서 자동 검색
3. 후보의 **이메일 자동 추출** (LinkedIn 프로필, 회사 홈페이지 footer 등에서)
4. 잠재고객의 **국가/직업/회사** 자동 파악
5. AI 가 영업 메일 초안 작성 — 출처(유튜버 vs 교수 vs 채용담당자)에 따라 톤 다르게, **국가 언어로 자동 번역**
6. **국가별 최적 발송 시간** 자동 계산 (예: 미국 화-목 오전 9시 ET)
7. 운영자가 웹에서 명단 확인 → 보낼 사람만 체크 → 일괄 발송
8. 1주일 답장 없으면 **자동 팔로업 메일** 작성
9. 잠재고객 상태 자동 추적: `가져옴 → 메일발송 → 응답 → 진행중 → 성사/실패`

### 🛡️ 자동으로 처리되는 것들

- **법규 준수**: 모든 메일 끝에 자동 수신거부 링크 + 회사 정보 footer (한국 정통망법 / EU GDPR / 미국 CAN-SPAM 자동 분기)
- **발송 속도 제한**: 분당/일일 한도 자동 관리 (Gmail 스팸 차단 방지)
- **다국어 번역**: 받는 사람 국가 기준 자동 번역
- **중복 방지**: 90일 안에 연락한 사람 자동 제외
- **수신거부 명단**: 한 번 unsubscribe 한 사람 영구 차단

### 💻 운영 방식

- 김규원 노트북에서 백엔드 프로그램 실행 (`.exe` 더블클릭 하나)
- 같은 노트북의 브라우저에서 `http://localhost:8000` 으로 웹 페이지 접속
- 모든 운영(메시지 검토, 발송, 정책 문서 편집)은 그 웹에서
- 데이터는 Supabase 클라우드 DB 에 저장되어 팀원이 다른 컴퓨터에서도 조회 가능
