## 2. 옵션 비교

### A. 클라우드 서버 (정공법, 추천)

```
사용자들 → 브라우저 → https://sales-auto.perso.com → Render BE → Supabase DB
```

- 인프라: Render (BE) + Supabase (DB) + Anthropic API (LLM)
- 서버 24/7, 누구나 브라우저로 접속
- **월 비용**: $12–25
  - Render Web Service Starter: $7 (always-on)
  - Anthropic API (Sonnet, 월 1000건 메시지 기준): $5–10
  - Supabase: $0 (무료 한도)
  - 도메인 (선택): $1/월
- 초기 셋업: 1–2시간
- 유지보수: 거의 없음 (Render 가 GitHub push 자동 배포)
- 단점: 비용 발생

**적합한 경우**:
- 영업 자동화에 진심
- 사용자 3명 이상
- 운영자가 컴퓨터 켜고 끄는 거 신경 안 쓰고 싶음

### B. 노트북 운영자 지정 (시범 단계용, 무료)

```
혜람님(또는 지정 운영자) 노트북 → BE 운영
  └─ cloudflared 무료 터널로 다른 팀원도 같은 URL 접속
  └─ Supabase 대시보드로 다른 팀원 데이터 조회
```

- 인프라: 운영자 노트북 + Supabase + claude CLI (무료)
- **월 비용**: $0 (전기료 ~$3 별도)
- 초기 셋업: 30분 (현재 상태에서 바로 가능)
- 유지보수: 운영자가 노트북 켜고 관리
- 단점:
  - **운영자 노트북 = 단일 장애점** (휴가, 출장, 고장 시 서비스 정지)
  - 운영자 부담 (sleep 차단, claude 로그인 갱신, 업데이트 등)
  - 다중 동시 사용 가능하나 운영자 PC 성능 영향

**적합한 경우**:
- MVP 시범 운영 (1주 –1개월)
- "정말 가치 있는지" 확인 단계
- 예산 없음

### C. 자체 호스팅 mini PC

```
회사에 mini PC 한 대 → 24/7 BE → cloudflared 외부 URL
```

- 인프라: NUC/Mac mini/Raspberry Pi + Supabase + claude CLI 또는 API
- **월 비용**: $5–10 (LLM만), 일회성 $200–400 (하드웨어)
- 초기 셋업: 2–3시간 (PC 셋업 + 네트워크)
- 유지보수: IT 담당이 정전/네트워크 이슈 대응
- 단점:
  - 회사 네트워크 셋업 필요 (방화벽, 외부 접근)
  - 하드웨어 고장 시 사람이 가서 처리
  - 시작 비용 발생

**적합한 경우**:
- 회사에 자체 인프라/IT 담당 있음
- 데이터 클라우드 외부 보관 거부감 있음
- 장기 운영 + 비용 절감 의도

## 3. 사용자 인증 방식 (아키텍처 결정 후 적용)

**김규원 의견: Google SSO (Workspace 계정 기반)**

- 회사 이메일 (`@perso.co` 같은 도메인) 로 원클릭 로그인
- 신규 사용자 추가/제거 = Google Workspace 에서 관리 (별도 사용자 DB 불필요)
- 누가 언제 어떤 메시지 승인했는지 로그 남음
- 사용자 경험 가장 깔끔
- 구현 시간: 약 4–6시간 (Google OAuth 통합)

**대안**:
- 공유 비밀번호 1개 (가장 단순, 누가 누른지 추적 불가)
- 개인별 이메일/비밀번호 계정 (DB 에 사용자 테이블 추가)

→ A 옵션 (클라우드) 채택 시 Google SSO 진행 권장. B 옵션 (노트북) 은 localhost 라 인증 불필요.

## 5. 김규원 (개발자) 추천

**A 옵션 (클라우드 + Google SSO)** 가 우리 케이스에 가장 적절하다고 판단:

1. **사용자가 비개발자 다수** → 누군가 노트북 켜놔야 한다는 부담 없어야
2. **김규원이 운영 안 함** → 운영자 PC 묶이는 구조 (B) 부적합
3. **월 $15 안팎은 영업 자동화 가치 대비 매우 저렴**
4. **회사 Google Workspace 있으면 SSO 셋업 간단**
5. **시범 운영 후 본격 운영 전환 시 추가 작업 없음** (그대로 사용)

**시범 운영을 무료로 먼저 해보고 싶으시면**: B 옵션 1–2주 → 검증 → A 로 이전. 단, 이전 작업이 약 1일 추가.

## 6. 결정 후 필요한 추가 작업 (개발자 김규원)

### A 채택 시 (15시간 추정)
- claude CLI → Anthropic API 로 통일 (이미 양쪽 지원, env 만 변경)
- browser-harness 토글 제거 (서버에선 무의미, Playwright 만 사용)
- Google OAuth 통합 (web UI 에 로그인)
- Render 배포 + 환경변수 셋업
- DNS / 도메인 연결
- HubSpot 웹훅 URL 클라우드로 변경
- 사용자 가이드 갱신 (혜람님용)

### B 채택 시 (3시간 추정)
- 현재 상태 그대로 + browser-harness 토글 (todo 087 처리)
- 지정 운영자 노트북 셋업 가이드 작성
- cloudflared 공유 URL 안내

### C 채택 시 (8시간 + 하드웨어 도착 대기)
- mini PC 셋업 가이드 (Linux + Chrome + claude CLI 로그인)
- 회사 네트워크 외부 노출 (cloudflared 또는 자체 reverse proxy)
- 정전 후 자동 재시작 스크립트
