# 설정 가이드

`.env` 파일의 모든 환경 변수에 대한 설명과 발급 방법입니다.

## .env 파일 위치

프로젝트 루트 폴더에 `.env` 파일이 있습니다.
`scripts\setup.bat`을 실행하면 `.env.example`에서 자동 복사됩니다.

편집: 메모장이나 VS Code로 열어서 값을 채우세요.
```
notepad .env
```

---

## 필수 설정

### INTERNAL_API_TOKEN

**용도:** 내부 API 보안 토큰. 모든 API 요청에 필요합니다.

**설정 방법:**
```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```
출력된 값을 복사하여 `.env`에 붙여넣기합니다.

**중요:** 이 값이 비어 있으면 서버가 모든 요청을 거부합니다.

## LLM (AI 엔진) 설정

### LLM_PROVIDER

**선택지:** `claude_cli` (기본값) 또는 `anthropic_api`

| 모드 | 설명 | 필요한 것 |
|---|---|---|
| `claude_cli` | Claude Code CLI를 subprocess로 호출 | Claude Code 설치 + 로그인 |
| `anthropic_api` | Anthropic API 직접 호출 | API 키 |

### CLAUDE_CLI_PATH

**기본값:** `claude`
**용도:** Claude CLI 실행 파일 경로. PATH에 있으면 그대로 둡니다.

### ANTHROPIC_API_KEY

**필수 조건:** `LLM_PROVIDER=anthropic_api`일 때만 필요

**발급 방법:**
1. [console.anthropic.com](https://console.anthropic.com) 접속
2. 로그인 후 왼쪽 메뉴에서 **API Keys** 클릭
3. **Create Key** 버튼 클릭
4. 키 이름 입력 후 생성
5. 생성된 키를 복사하여 `.env`에 붙여넣기

### ANTHROPIC_MODEL

**기본값:** `claude-sonnet-4-6`
**용도:** 사용할 Claude 모델. 비용과 성능의 균형에 따라 선택합니다.

## HubSpot 설정

### HUBSPOT_PRIVATE_APP_TOKEN

**용도:** HubSpot CRM API 접근용 토큰

**발급 방법:**
1. [app.hubspot.com](https://app.hubspot.com) 접속 → 설정(톱니바퀴)
2. 왼쪽 메뉴: **Integrations** → **Private Apps**
3. **Create a private app** 클릭
4. 앱 이름 입력 (예: "Sales Automation")
5. **Scopes** 탭에서 다음 권한 추가:
   - `crm.objects.contacts.read` / `write`
   - `crm.objects.deals.read` / `write`
   - `crm.objects.companies.read`
   - `sales-email-read`
6. **Create app** 클릭 후 토큰 복사

### HUBSPOT_INBOUND_PIPELINE_ID

**선택사항:** 인바운드 문의가 들어갈 딜 파이프라인 ID
HubSpot 설정 → 딜 → 파이프라인에서 확인할 수 있습니다.

### HUBSPOT_OWNER_ID

**선택사항:** 생성된 레코드의 기본 담당자 ID

## 이메일 발송 설정

### EMAIL_PROVIDER

**선택지:** `hubspot` (기본값) 또는 `smtp`

- `hubspot`: HubSpot Engagements API로 발송 (HubSpot 토큰 필요)
- `smtp`: Gmail 등 SMTP 서버로 직접 발송

### Gmail App Password 발급 방법 (SMTP용)

1. Google 계정에서 **2단계 인증** 활성화 (필수 선행 단계)
2. [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) 접속
3. 앱 이름 입력 (예: "Sales Automation")
4. **생성** 클릭
5. 표시되는 16자리 비밀번호를 `SMTP_PASSWORD`에 입력

```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your-email@gmail.com
SMTP_PASSWORD=xxxx xxxx xxxx xxxx
SMTP_FROM_NAME=영업팀
SMTP_FROM_EMAIL=your-email@gmail.com
```

**주의:** 일반 Gmail 비밀번호가 아닌 **앱 비밀번호**를 사용해야 합니다.

## Slack 설정

### SLACK_BOT_TOKEN

**용도:** 승인 카드 발송, 리포트 전달, 에러 알림

**발급 방법:**
1. [api.slack.com/apps](https://api.slack.com/apps) 접속
2. **Create New App** → **From scratch**
3. 앱 이름과 워크스페이스 선택
4. 왼쪽 메뉴: **OAuth & Permissions**
5. **Bot Token Scopes**에 추가:
   - `chat:write`
   - `chat:write.public`
6. **Install to Workspace** 클릭
7. **Bot User OAuth Token** 복사 (`xoxb-` 로 시작)

### SLACK_APPROVAL_CHANNEL_ID

**용도:** 승인 카드가 도착할 Slack 채널

**확인 방법:**
1. Slack에서 해당 채널 이름을 우클릭
2. **채널 세부정보 보기** 클릭
3. 하단의 **채널 ID** 복사 (예: `C0123456789`)

### SLACK_ERROR_CHANNEL_ID

**선택사항:** 에러 알림을 받을 별도 채널. 미설정 시 승인 채널로 발송됩니다.

## Microsoft Teams 설정

### TEAMS_WEBHOOK_URL

**용도:** Slack 대신 Teams로 승인 카드와 리포트를 받을 때

**발급 방법:**
1. Teams에서 알림을 받을 채널 선택
2. 채널 이름 옆 **...** 클릭 → **커넥터**
3. **Incoming Webhook** 검색 → **구성**
4. 이름 입력 후 **만들기**
5. 생성된 URL 복사

## YouTube 설정

### YOUTUBE_API_KEY

**용도:** 아웃바운드 YouTube 소스에서 채널 검색 시 사용

**발급 방법:**
1. [console.cloud.google.com](https://console.cloud.google.com) 접속
2. 새 프로젝트 생성 또는 기존 프로젝트 선택
3. **API 및 서비스** → **라이브러리**
4. **YouTube Data API v3** 검색 → **사용 설정**
5. **API 및 서비스** → **사용자 인증 정보**
6. **사용자 인증 정보 만들기** → **API 키**
7. 생성된 키 복사

## LinkedIn 스크래핑 설정

### LINKEDIN_SCRAPING_ENABLED

**기본값:** `false`
**주의:** LinkedIn 이용약관(ToS)에 따른 위험이 있습니다. 운영자 책임하에 사용하세요.

### LINKEDIN_SESSION_COOKIE

**용도:** Playwright 기반 LinkedIn 댓글 스크래핑용

**확인 방법:**
1. 브라우저에서 LinkedIn에 로그인
2. 개발자 도구 열기 (F12)
3. **Application** 탭 → **Cookies** → `www.linkedin.com`
4. `li_at` 쿠키의 값 복사

**주의:** 이 쿠키는 세션이 만료되면 재발급해야 합니다.

### LINKEDIN_API_TOKEN

**용도:** 파트너 티어 LinkedIn API 토큰 (있는 경우)

대부분의 경우 이 토큰은 없으므로 비워 둡니다. Playwright 폴백이 사용됩니다.

## 동작 조정

| 변수 | 기본값 | 설명 |
|---|---|---|
| `AUTO_SEND_THRESHOLD` | `1.01` | 자동 발송 기준 (>1.0이면 항상 사람 승인 필요) |
| `OUTBOUND_COOLDOWN_DAYS` | `90` | 같은 이메일에 재연락 금지 기간 (일) |
| `FOLLOWUP_AFTER_DAYS` | `4` | 답장 없으면 팔로업 발송까지 대기 일수 |
| `ICP_THRESHOLD` | `50` | ICP 점수 최소 기준 (미달 시 건너뜀) |
| `DAILY_REPORT_HOUR` | `18` | 일간 리포트 생성 시각 (24시간) |
| `WEEKLY_REPORT_DOW` | `5` | 주간 리포트 요일 (0=월, 5=토) |
