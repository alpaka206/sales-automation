# PERSO AI 요금제 (perso.ai/pricing 기준)

> **인바운드 가격 문의 응대 원칙**: 고객의 사용 사례에 맞는 플랜을 **실제 가격과 함께 추천**하세요. 아래 표의 값만 사용하고, 없는 숫자는 만들지 마세요. 대규모/엔터프라이즈 시그널일 때만 가격 대신 영업 미팅을 제안합니다. 가격은 항상 [perso.ai/pricing](https://perso.ai/pricing)이 최신 기준입니다.

- 신규 가입 **프로모션 적용 시** Starter $3.50 / Creator $14.50 / PRO $49.50 수준까지 할인될 수 있습니다(시점에 따라 변동).
- 크레딧은 **사용한 초(秒)만큼만 차감**(pay only for seconds used).
- Creator·PRO는 **슬로우모드 더빙 무제한**(크레딧 무소모). Free·Starter는 슬로우모드 더빙 가능하나 길이 제한.
- Booster(동시 처리/대기열): Free·Starter 동시 1·대기 1 / Creator 동시 1·대기 2 / PRO 동시 2·대기 3 / Enterprise 커스텀.
- 모든 유료 플랜 공통: 무제한 재생성, 무제한 저장, **워터마크 없음**.

> **계약형 B2B(셀프서브 구독으로 결제하는 비즈니스 플랜)** 는 PRO와 Enterprise 사이 구간입니다. 상세 가격·크레딧은 [[perso_business_plan]] 참조.

## 공통 핵심 기능 (전 플랜)

- **더빙**: 원본 음성 유지, **99개 이상 언어**
- **립싱크 더빙**: 입 모양 정밀 동기화
- **음성→텍스트(STT)**: 스크립트 + 요약 + 액션 아이템
- **오디오 분리**: 트랙 분리·믹싱
- **스크립트 편집**: 문장 단위 미세 조정
- **커스텀 용어집**, **SRT 업로드**(정확한 싱크), **팀 협업/공유 워크스페이스**

## "무제한"·공정 사용 정책 안내 (응대용)

각 더빙 플랜은 **무제한 요금제**로 운영됩니다. 대부분의 일상적 콘텐츠 제작 범위에서는 제약 없이 사용 가능하나, **공정 사용 정책(Fair Use Policy)** 에 따라 서버 안정성을 위해 과도한 사용이 감지되면 일시적으로 제한될 수 있습니다. 이 경우 **최초 영상 생성 시점 기준 일정 시간(약 24시간) 후 사용량이 자동 초기화**되어 다시 자유롭게 생성할 수 있습니다. → 일반 사용 환경에서는 '무제한'처럼 이용 가능하며 내부적으로 합리적 기준이 작동해 품질을 유지합니다.

## 사용 사례별 추천 (인바운드 답장용)

- **처음 써보는 개인 / 짧은 영상** → **Free**로 체험 후 더 필요하면 **Starter($6.99/월)**.
- **유튜버·크리에이터·1인~소규모** → **Creator($29/월, 연 결제 시 최대 26%↓)** — 가성비 기본 추천. 영상 15분·월 1,800 크레딧·슬로우모드 무제한.
- **전문 제작·대량·4K 필요** → **PRO($99/월)** — 월 6,000 크레딧·영상 30분·4K.
- **대규모 조직 / 전용 서버 / 커스텀 보안·구성 / 60분 영상** → **Enterprise** — 가격은 사용 환경에 따라 달라지므로 **영업 미팅** 제안.

## 응대 어조 요약

- 개인/크리에이터 시그널(개인 이메일·유튜브 채널·1인 운영) → 위 추천 플랜을 **가격과 함께** 안내 + 자가 가입 링크 안내 가능.
- 엔터프라이즈 시그널(대기업 도메인·다수 좌석/스페이스·커스텀 세팅·보안/계약 언급·대량) → 셀프서브 가격 나열 X, **Enterprise 권유 + 15분 통화 제안**.
- 환불/SSO/보안/계약 등 정책 질문은 즉답 대신 "내부 검토 후 영업일 1~2일 내 회신" 약속.
