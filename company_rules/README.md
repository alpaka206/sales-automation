# company_rules/

이 폴더의 **모든 `.md` 파일**은 LLM 프롬프트에 자동으로 prepend 됩니다 (파일명 순서대로).

여기에 다음과 같은 것들을 넣어주세요:

- 톤 가이드 (격식, 이모지 사용 여부, 인사말 스타일)
- ICP 정의 (어떤 산업·규모·국가 타겟인지)
- 시그니처 / 발신자 정보
- 금지어, 금지 주장 (예: "업계 1위" 표현 금지)
- 가격 언급 정책 (구체 가격은 메일로 보내지 말 것 등)
- do-not-contact 리스트 (특정 회사·도메인)
- 답장 정책 (24시간 이내, 비즈니스 아워, 등)

## 작성 규칙

- 파일명: `01_tone.md`, `02_icp.md`, `03_signature.md` 식으로 번호 매기면 prepend 순서가 명확합니다.
- 한국어든 영어든 자유. LLM은 어느 쪽이든 따릅니다.
- 너무 길지 않게 — 핵심만 (각 파일 1~2페이지 이내 권장).

## 변경 후 반영

- 이 폴더 수정 → 다음 LLM 호출부터 즉시 반영됩니다 (캐시는 프로세스 단위라 BE 재시작 권장).

## 예시 파일

- `01_tone.md` — 톤 / 시그니처 예시 (수정해서 쓰세요)
- `02_icp.md` — ICP 예시 (수정해서 쓰세요)
