# ICP — PERSO AI 의 이상적 고객

## 타겟 정의

PERSO AI 는 **다국어 콘텐츠 워크플로우 자동화** 가 가치이므로 ICP 는 다음 시그널을 가진 조직.

### 산업 (가점 대상)

- **미디어·콘텐츠** — 방송사·OTT·MCN·유튜브 네트워크
- **이커머스·H&B** — 글로벌 브랜드 / 라이브 커머스 운영
- **뷰티·패션** — 다국어 광고·캠페인 영상 다수 제작
- **에듀테크** — 다국어 강의 콘텐츠
- **B2B SaaS** — 자체 마케팅 영상 운영
- **엔터테인먼트·아이돌·웹툰** — IP 글로벌 확산

### 규모

- **셀프서브 트랙**: 1인 크리에이터 ~ 50명 이하 팀 → Creator/PRO 플랜
- **엔터프라이즈 트랙**: 콘텐츠팀 자체 보유 + 다국가 운영 + 다수 스페이스 필요 → 별도 계약

### 지역 우선순위

- 1순위: 한국, 일본, 동남아 (싱가포르·인도네시아·베트남·태국·말레이시아·필리핀)
- 2순위: 영어권 (미국·영국·호주) — ESTsoft Inc. 싱가포르 법인 경유
- 보류: EU (GDPR 부담), 중국 (결제·규제 별도)

## 점수 가점 (LLM 참고용 / 100점 만점)

- **+20**: 위 산업에 속하고 글로벌 콘텐츠 운영 중 (영문·다국어 사이트 보유)
- **+15**: 자체 도메인 사용 (gmail/naver/yahoo 등 개인 메일 X)
- **+15**: 한국·일본·동남아 도메인 (`.kr`, `.jp`, `.sg`, `.id`, ...)
- **+10**: 회사 홈페이지에 "다국어", "글로벌", "international", "global", "localize" 같은 키워드
- **+10**: LinkedIn 직원 수 10명 이상 (성장 단계 시그널)
- **+10**: 최근 6개월 채용 공고 (콘텐츠·마케팅·로컬라이제이션 직무) 게시
- **+5**: 도메인 분석 결과 industry 가 위 산업과 매칭

## 점수 감점

- **−30**: 경쟁사 도메인 (do-not-contact 리스트 매칭)
- **−25**: 개인 이메일 도메인 (gmail / naver / daum / yahoo / hotmail / outlook / icloud / kakao / hanmail / nate)
- **−20**: ESTsoft 본인 회사 도메인 (`@estsoft.com`, `@perso.ai` 등)
- **−15**: 본사가 ICP 외 지역 (EU·중국·중동)
- **−10**: 도메인 분석에서 confidence=low (정보 부족)

## do-not-contact 리스트 (예시 — 실제 값으로 교체)

- 본인 회사 도메인: `estsoft.com`, `perso.ai`, `est-inc.com`
- 명백한 경쟁사 (별도 리스트 관리)
- 이미 엔터프라이즈 계약 진행 중인 고객사 (영업팀 컨택 우선)
- email_suppression 테이블에 등록된 unsubscribe·bounce 주소

## 임계값

- 점수 **70+ 자동 발송 큐**, 50~69 운영자 검토, 50 미만 스킵
- (단 `AUTO_SEND_THRESHOLD` 가 1.01 이면 모든 점수에서 사람 승인 필수 — 기본값)
