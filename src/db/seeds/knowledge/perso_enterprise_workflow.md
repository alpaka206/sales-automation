# 엔터프라이즈 도입 프로세스 (운영자 참고용)

## 일반 구독 vs 엔터프라이즈 차이

| 변수 | 일반 구독 (Starter/Creator/PRO) | 엔터프라이즈 |
|------|--------------------------------|--------------|
| 결제 금액 | 플랜별 고정 ($6.99 / $21 / $73) | 고객사별 커스텀 계약 |
| 결제 수단 | Stripe 단일 | Stripe / 포트원 / 계좌이체 혼재 |
| 결제 주기 | 월간·연간 자동 결제 | 일시불 / 월 할부 / 분기 할부 |
| 크레딧 총량 | 플랜별 고정 | 계약서 기반 커스텀 |
| 스페이스 수 | 1개 | 1~N개 (고객사 조직 구조에 따라) |
| 스페이스당 크레딧 | 해당 없음 | 균등 배분 또는 스페이스별 차등 |
| Dubbing 세팅 | 플랜별 고정 | concurrent job 수·queue 수 커스텀 |

## 도입 4단계

1. **결제 확인** — 결제 수단별 (Stripe 대시보드 / 포트원 어드민 / 경영지원팀 입금 대조)
2. **플랜 세팅값 구성** — 백오피스에서 concurrent job·queue·Dubbing 파라미터 입력
3. **스페이스 개설** — 신규 요청 수만큼 백오피스에서 개별 생성 (기존 고객은 활용 또는 부족 시 추가)
4. **스페이스별 크레딧 할당** — 균등 또는 차등 배분으로 각 스페이스에 개별 지급

### 시나리오별 적용

| 시나리오 | 초회 | 매월 반복 |
|----------|------|----------|
| 일시불 + 신규 | Step 1→2→3→4 | 없음 |
| 할부 + 신규 | Step 1→2→3→4 | Step 1→4 반복 |
| 일시불 + 기존 | Step 1→2→3(필요시)→4 | 없음 |
| 할부 + 기존 | Step 1→2→3(필요시)→4 | Step 1→4 반복 |

## 답장 시 어조

- 대기업 도메인 + "조직 N개 스페이스 필요", "보안 검토", "SSO", "계약서", "법무" 같은 키워드 → **엔터프라이즈 트랙으로 라우팅**. 셀프서브 가격 안내 금지.
- 첫 답장: 사용 시나리오·예상 사용량·결제 주기 3가지를 가볍게 묻는 짧은 미팅 (30분) 제안.
- 케이스 스터디 언급 가능 — "국내 대기업 콘텐츠팀 도입 사례가 있어 관련 자료를 미팅 때 공유드릴 수 있습니다." (구체 고객사명은 NDA 가 풀린 경우에만 명시).
- 보안·법무 질문은 즉답하지 말고 "내부 검토 후 영업일 1~2일 내 회신" 약속.
