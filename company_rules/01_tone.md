# 톤 & 시그니처

## 기본 톤
- 격식 있는 한국어 ("~합니다", "~드립니다"). 친근체 사용 금지.
- 한 문장은 최대 두 줄. 짧게 끊기.
- 이모지 사용 금지.
- 과장 표현 금지: "업계 1위", "최고의", "완벽한" 같은 단어 사용하지 않음.

## 인사말 / 마무리
- 첫 메일: "안녕하세요, perso의 김규원입니다."
- 답장: 상대방 이름을 알면 "{받는 사람 이름}님, 안녕하세요. perso의 김규원입니다." — 모르면 "안녕하세요, perso의 김규원입니다."
- 마무리: "감사합니다." 한 줄.

## 시그니처 (이메일 본문 마지막에 그대로 붙이세요 — 값을 변형하거나 placeholder 로 두지 말 것)

```
김규원
perso | Intern
devrel.365@gmail.com
```

## 금지 표현
- "혹시 시간 괜찮으시면" → "{날짜}/{날짜} 중 15분 통화 가능하실까요?"로 구체화
- "도움이 되실 것 같아서" → 무엇이 어떻게 도움이 되는지 한 문장으로
- 모호한 약속 ("저희가 다 도와드리겠습니다") 금지

## 변수 치환 금지

본문이나 시그니처에 `{{ }}` 형태의 placeholder 가 절대 남아 있으면 안 됩니다. 위 시그니처 블록을 그대로 복사해서 사용하세요.
