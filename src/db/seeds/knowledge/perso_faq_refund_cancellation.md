# 환불·구독취소 정책 및 응대 가이드

> 환불 문의 1차 응대 시: **결제일·플랜·서비스 사용 시작 여부** 3가지를 먼저 확인하세요. 정확한 환불 가능 여부/금액은 내부 심사(영업일 5~10일) 후 안내합니다. 공식 환불 정책 URL을 메일에 직접 첨부하지 말 것(내부 처리 절차).

## 1. 환불 가능 기준

**청약철회(표준)** — 다음을 **모두** 충족 시 환불 심사 가능:
- 결제한 유료 서비스를 **전혀 사용하지 않았을 것** (Free Trial 중 콘텐츠 생성도 사용으로 간주)
- 결제일 또는 서비스 이용가능일 중 **늦은 날로부터 7일 이내** 요청
- 환불액: 결제 금액 − PG 수수료

**환불 불가**: 결제일 30일 초과 / 약관 위반 / 부정 사용 / 프로모션·할인 구매분 / 엔터프라이즈 계약분 / 이미 크레딧 사용분(미사용분만). **AI 생성 결과물 품질 불만족·기대와 다른 결과는 환불 사유가 아님.**

**특별 처리**: 시스템 오류 피해 시 100% 환불, 서비스 중단 시 별도 보상.

## 2. 사용량 기반 환불 산정 (연간 결제·강성·내부 고객 — 운영자 참고용)

> 고객에게 숫자 공식을 그대로 보내지 말고, 산정 후 **최종 환불액만** 안내하세요.

```
환불액 = 결제금액 − (PG 수수료 + 일일 사용료 × 사용 일수)
일일 사용료 = (정상가 연간 요금 ÷ 12개월) ÷ 해당 월 일수   (소수점 둘째 자리 반올림)
```

- **PG 수수료**: Stripe 실수수료와 결제액의 6% 중 **높은 쪽** 적용.
- **정상가 기준 계산**: 연간 할인가가 아니라 **월정가 × 12** 기준으로 사용량 산정. (정상가는 현재 요금제 [[perso_pricing]] 기준)
- 처리: 결제·사용 이력 확인 → 환불액 계산 → 고객 동의 → 환불(영업일 3~5일) → Stripe 구독 취소 → 백오피스 크레딧 취소 → 완료 알림.

> 예시(산정 방식 설명용): 결제 $348, PG 수수료 $20.88(또는 Stripe $21), 정상가 월정가 기준 일일 사용료 ≈ $1.3, 2일 사용 → 환불액 ≈ $348 − ($21 + $2.6) = $324.4. *단가는 현재 정가 기준으로 다시 계산할 것.*

## 3. 고객 응대 템플릿 (한국어)

### 3-1. 환불 정책 안내 (1차)

```
안녕하세요, 고객님. Perso AI 입니다.
저희 서비스는 이용약관에 따라 유료 서비스 결제 후 원칙적으로 환불이 어려운 점 양해 부탁드립니다.
다만, 아래 조건을 모두 충족하시는 경우 청약철회를 통한 환불 심사가 가능합니다.
- 결제한 서비스를 전혀 사용하지 않으셨을 것
- 결제일 또는 서비스 이용 가능일 중 늦은 날로부터 7일 이내 요청하셨을 것

위 조건에 해당하신다면 다음 증빙 자료를 제출해 주세요.
- 서비스 미사용을 증명할 수 있는 PERSO.ai 워크스페이스 홈화면, All Videos 캡처 이미지
- 결제 시 수신하신 영수증 및 청구서 번호

확인 후 이용약관에 근거하여 PG 수수료를 공제한 금액을 5~10 영업일 내로 환급 처리해 드리겠습니다.
환불이 아닌 구독 취소 예약만 원하시면, 워크스페이스 세팅 > 구독 탭에서 '구독 취소 예약'을 눌러주세요(이미 결제된 금액은 환불되지 않으며 다음 결제 주기부터 취소됩니다).
실례가 안 된다면 환불을 요청하신 사유를 여쭤도 될까요? 서비스 개선에 소중히 반영하겠습니다.
```

### 3-2. 증빙 접수 후

```
네, `고객명` 님. 환불 내역 접수되었습니다.
환불 담당 부서의 확인 및 심사 후 다시 안내드리겠습니다(영업일 기준 5~10일 소요될 수 있습니다). 감사합니다.
```

### 3-3. 환불 완료 안내

```
안녕하세요, `고객명` 님.
요청해주신 환불이 결제 수수료를 제외한 금액으로 정상적으로 완료되었습니다.
계좌/카드사 사정에 따라 확인까지 추가 기간이 소요될 수 있습니다.
다시 Perso AI를 찾으실 때까지 더 만족스러운 경험을 제공하도록 노력하겠습니다. 감사합니다.
```

### 3-4. 환불 불가 안내

```
안녕하세요, 고객님. Perso AI 입니다.
제출해 주신 자료를 검토한 결과, 아쉽게도 현재 상황은 청약철회 조건에 해당되지 않아 환불이 어렵습니다.
(사유 예: 서비스 사용 내역 확인됨 / 7일 기간 경과 / Free Trial 중 콘텐츠 생성 확인)
환불이 아닌 구독 취소 예약을 원하시면 워크스페이스 세팅 > 구독 탭에서 신청하실 수 있습니다.
공정한 서비스 운영을 위해 정책을 일관되게 적용해야 하는 점 양해 부탁드립니다. 감사합니다.
```

## 4. 구독 취소 예약 방법 안내

```
안녕하세요 고객님. Perso AI 구독 해지는 '구독 취소 예약'으로 가능합니다.
좌측 상단 배너 클릭 > Workspace Settings > Subscription 탭에서 구독 해지를 신청하실 수 있으며,
하단에 '구독 해지 예정일'이 안내 메시지로 표시되면 정상적으로 취소 예약이 완료된 상태입니다.
진행 중 어려움이 있으시면 언제든 말씀 주세요. 감사합니다.
```

> 운영자가 직접 취소 처리해 준 경우: "`고객 계정 이메일` 계정에 대한 구독 취소가 정상적으로 처리되었음을 안내드립니다 …" (구독취소 완료 안내 템플릿).

## 5. 해지방어 (환불 요청 → 재고 유도)

> 환불은 정책상 가능함을 인정하되, **대안 1개**를 제시해 재고를 유도. "불가능"이 아니라 대안 중심.

- **더빙 일일제한 불만**: AI 더빙은 자원 소모가 커 공정 사용 정책을 운영 → 과도 사용 시 일시 제한되나 일정 시간 후 초기화. 1개월 작업량을 잘 배분하면 크레딧 과금 타사보다 저렴하게 다량 더빙 가능. 작업량이 많다면 PRO(x3)/Enterprise 상위 플랜도 권장. "조금 더 생각해보고 결정해 주시면 신속히 도와드리겠습니다."
- **사용량 없는 고객**: 약관상 환불 가능해 보이나, 어떤 부분이 기대에 못 미쳤는지 여쭙고 현재 플랜에서 더 나은 결과를 얻도록 돕겠다고 제안 → "환불은 조금만 더 생각해보고 다시 요청해 주실 수 있을까요?"
- **Starter 5분 제한 불만(15분 더빙 필요)**: 결제 7일 내·미사용이면 환불 가능. 다만 외부 편집툴로 5분 단위 분할 후 3회 업로드하는 방법을 권장.
- **크레딧/Fast Speed 정책 변경 불만**: 기존 일일한도 도달 시 다음날까지 중단되던 구조 → 신규 정책은 소진 후에도 무제한 생성 가능 구조로 개선. 단일 영상 5분이지만 분할 생성 시 오히려 더 많은 작업 가능 → 더 유리한 정책임을 안내하고 재이용 권유.
