# 설정 가이드

`.env` 파일의 모든 환경 변수에 대한 설명과 발급 방법입니다.

## .env 파일 위치

프로젝트 루트 폴더에 `.env` 파일이 있습니다.
`scripts\setup.bat`을 실행하면 `.env.example`에서 자동 복사됩니다.

편집: 메모장이나 VS Code로 열어서 값을 채우세요.
```
notepad .env
```

---

## 필수 설정

### INTERNAL_API_TOKEN

**용도:** 내부 API 보안 토큰. 모든 API 요청에 필요합니다.

**설정 방법:**
```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```
출력된 값을 복사하여 `.env`에 붙여넣기합니다.

**중요:** 이 값이 비어 있으면 서버가 모든 요청을 거부합니다.

## LLM (AI 엔진) 설정

LLM은 **Gemini (Vertex AI)** 단독입니다. API 키가 아니라 서비스 계정 JSON으로 인증합니다.

### GOOGLE_CREDENTIALS_JSON

**필수.** Vertex AI 서비스 계정 JSON 전체 내용을 한 줄 문자열로 넣습니다.

**발급 방법:**
1. [Google Cloud Console](https://console.cloud.google.com) → IAM 및 관리자 → 서비스 계정
2. 서비스 계정 생성 후 **Vertex AI User** 역할 부여
3. 키 → 새 키 만들기 → JSON 다운로드
4. JSON 파일 내용을 `.env`의 `GOOGLE_CREDENTIALS_JSON=` 에 붙여넣기

### GOOGLE_CLOUD_PROJECT

**선택.** 비우면 JSON 안의 `project_id`를 사용합니다.

### GOOGLE_CLOUD_LOCATION

**기본값:** `global`
**용도:** Vertex AI 리전. 예) `global`, `us-central1`, `asia-northeast1`.

### GEMINI_MODEL / GEMINI_MODEL_PRO (하이브리드 모델)

판단 난이도에 따라 두 모델을 나눠 씁니다(코드가 단계별로 자동 선택).

| 환경변수 | 기본값 | 쓰이는 단계 |
|----------|--------|-------------|
| `GEMINI_MODEL` | `gemini-2.5-flash` | 분류, 점수 조정, 문서 라우팅, 도메인 분석 (빠르고 저렴) |
| `GEMINI_MODEL_PRO` | `gemini-2.5-pro` | 인바운드 답장 초안, 아웃바운드 오프닝 이메일, 팔로업 초안 (품질 중요) |

- 비용을 더 줄이려면 `GEMINI_MODEL_PRO`도 flash로 낮출 수 있습니다.
- 최고 품질을 원하면 둘 다 pro로 올릴 수 있으나 비용·지연이 늘어납니다.

### Google Sheets 미러 (선택)

인바운드로 처리된 문의를 Google 시트에 한 행씩 자동 정리합니다. **Vertex와 별도의 전용 서비스계정**을 씁니다.

| 환경변수 | 설명 |
|----------|------|
| `GSHEETS_ENABLED` | `true`면 활성화 (기본 `false`) |
| `GOOGLE_SHEETS_CREDENTIALS_JSON` | Sheets 전용 서비스계정 JSON 전체 |
| `GOOGLE_SHEETS_SPREADSHEET_ID` | 시트 URL `/d/<ID>/edit`의 ID |
| `GOOGLE_SHEETS_INBOUND_TAB` | 기록할 워크시트(탭) 이름. 기본 `Inbound` |

**준비:** ① Google Cloud에서 서비스계정 생성 → JSON 발급, ② Google Sheets API 사용 설정, ③ 대상 시트를 그 서비스계정 client email에 **편집자**로 공유. 첫 기록 시 헤더 행이 자동 생성됩니다. 시트 기록 실패는 인바운드 처리를 막지 않습니다(베스트 에포트).

## HubSpot 설정

### HUBSPOT_PRIVATE_APP_TOKEN

**용도:** HubSpot CRM API 접근용 토큰

**발급 방법:**
1. [app.hubspot.com](https://app.hubspot.com) 접속 → 설정(톱니바퀴)
2. 왼쪽 메뉴: **Integrations** → **Private Apps**
3. **Create a private app** 클릭
4. 앱 이름 입력 (예: "Sales Automation")
5. **Scopes** 탭에서 다음 권한 추가:
   - `crm.objects.contacts.read` / `write`
   - `crm.objects.deals.read` / `write`
   - `crm.objects.companies.read`
   - `sales-email-read`
6. **Create app** 클릭 후 토큰 복사

### HUBSPOT_INBOUND_PIPELINE_ID

**선택사항:** 인바운드 문의가 들어갈 딜 파이프라인 ID
HubSpot 설정 → 딜 → 파이프라인에서 확인할 수 있습니다.

### HUBSPOT_OWNER_ID

**선택사항:** 생성된 레코드의 기본 담당자 ID

## 이메일 발송 설정

### EMAIL_PROVIDER

**선택지:** `hubspot` (기본값) 또는 `smtp`

- `hubspot`: HubSpot Engagements API로 발송 (HubSpot 토큰 필요)
- `smtp`: Gmail 등 SMTP 서버로 직접 발송

### SMTP 제공자 비교

| 제공자 | 호스트 | 포트 | 무료 한도 | 비고 |
|---|---|---|---|---|
| Gmail | `smtp.gmail.com` | 587 | 500통/일 | 2단계 인증 + 앱 비밀번호 필요 |
| Outlook | `smtp-mail.outlook.com` | 587 | 300통/일 | 개인 MS 계정 또는 Microsoft 365 |
| Brevo | `smtp-relay.brevo.com` | 587 | 300통/일 | 무료 가입, SMTP 키 발급 간단 |
| SendGrid | `smtp.sendgrid.net` | 587 | 100통/일 | USERNAME은 항상 `apikey` 고정 |

`.env.example`에 4가지 제공자 예시가 주석으로 포함되어 있습니다. 사용할 제공자의 주석을 해제하고 값을 채우세요.

### Gmail App Password 발급 방법

1. Google 계정에서 **2단계 인증** 활성화 (필수 선행 단계)
2. [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) 접속
3. 앱 이름 입력 (예: "Sales Automation")
4. **생성** 클릭
5. 표시되는 16자리 비밀번호를 `SMTP_PASSWORD`에 입력

```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your-email@gmail.com
SMTP_PASSWORD=xxxx xxxx xxxx xxxx
SMTP_FROM_NAME=영업팀
SMTP_FROM_EMAIL=your-email@gmail.com
```

**주의:** 일반 Gmail 비밀번호가 아닌 **앱 비밀번호**를 사용해야 합니다.

### Outlook 설정 방법

1. Outlook.com 또는 Microsoft 365 계정으로 로그인
2. 계정 보안 설정에서 **2단계 인증** 활성화
3. **앱 비밀번호** 생성 (Microsoft 365의 경우 관리자 설정 필요)

```
SMTP_HOST=smtp-mail.outlook.com
SMTP_PORT=587
SMTP_USERNAME=your-email@outlook.com
SMTP_PASSWORD=앱 비밀번호
```

### Brevo (구 Sendinblue) 설정 방법

1. [app.brevo.com](https://app.brevo.com) 무료 가입
2. 좌측 메뉴 **Settings** > **SMTP & API**
3. **SMTP** 탭에서 키 생성
4. 표시되는 SMTP 키를 `SMTP_PASSWORD`에 입력

```
SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_USERNAME=가입 이메일
SMTP_PASSWORD=Brevo SMTP 키
```

### SendGrid 설정 방법

1. [sendgrid.com](https://sendgrid.com) 무료 가입
2. **Settings** > **API Keys** > **Create API Key**
3. **Full Access** 또는 **Mail Send** 권한 선택
4. 생성된 API 키를 `SMTP_PASSWORD`에 입력

```
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USERNAME=apikey
SMTP_PASSWORD=SendGrid API Key
```

**참고:** SendGrid의 SMTP_USERNAME은 항상 문자열 `apikey`입니다 (자신의 이메일이 아님).

## Slack 설정

### SLACK_BOT_TOKEN

**용도:** 승인 카드 발송, 리포트 전달, 에러 알림

**발급 방법:**
1. [api.slack.com/apps](https://api.slack.com/apps) 접속
2. **Create New App** → **From scratch**
3. 앱 이름과 워크스페이스 선택
4. 왼쪽 메뉴: **OAuth & Permissions**
5. **Bot Token Scopes**에 추가:
   - `chat:write`
   - `chat:write.public`
6. **Install to Workspace** 클릭
7. **Bot User OAuth Token** 복사 (`xoxb-` 로 시작)

### SLACK_APPROVAL_CHANNEL_ID

**용도:** 승인 카드가 도착할 Slack 채널

**확인 방법:**
1. Slack에서 해당 채널 이름을 우클릭
2. **채널 세부정보 보기** 클릭
3. 하단의 **채널 ID** 복사 (예: `C0123456789`)

### SLACK_ERROR_CHANNEL_ID

**선택사항:** 에러 알림을 받을 별도 채널. 미설정 시 승인 채널로 발송됩니다.

## YouTube 설정

### YOUTUBE_API_KEY

**용도:** 아웃바운드 YouTube 소스에서 채널 검색 시 사용

**발급 방법:**
1. [console.cloud.google.com](https://console.cloud.google.com) 접속
2. 새 프로젝트 생성 또는 기존 프로젝트 선택
3. **API 및 서비스** → **라이브러리**
4. **YouTube Data API v3** 검색 → **사용 설정**
5. **API 및 서비스** → **사용자 인증 정보**
6. **사용자 인증 정보 만들기** → **API 키**
7. 생성된 키 복사

## LinkedIn 스크래핑 설정

### LINKEDIN_SCRAPING_ENABLED

**기본값:** `false`
**주의:** LinkedIn 이용약관(ToS)에 따른 위험이 있습니다. 운영자 책임하에 사용하세요.

### LINKEDIN_SESSION_COOKIE

**용도:** Playwright 기반 LinkedIn 댓글 스크래핑용

**확인 방법:**
1. 브라우저에서 LinkedIn에 로그인
2. 개발자 도구 열기 (F12)
3. **Application** 탭 → **Cookies** → `www.linkedin.com`
4. `li_at` 쿠키의 값 복사

**주의:** 이 쿠키는 세션이 만료되면 재발급해야 합니다.

### LINKEDIN_API_TOKEN

**용도:** 파트너 티어 LinkedIn API 토큰 (있는 경우)

대부분의 경우 이 토큰은 없으므로 비워 둡니다. Playwright 폴백이 사용됩니다.

## 동작 조정

|---|---|---|
