# 테스트 가이드

지금 시스템에서 직접 돌려볼 수 있는 시나리오들을 정리한 문서입니다.

## 한 줄 요약: 어떤 명령을 언제 쓰나

| 명령 | 언제 |
|---|---|
| `pytest -q` | 코드 변경 후 — 170 단위 테스트 (외부 호출 없음, 10초) |
| `python -m src.cli doctor` | 처음 세팅했을 때 환경변수 / DB / CLI 다 있는지 사전점검 |
| `python -m src.cli healthcheck` | 실제 외부 연결 (HubSpot, Supabase, SMTP, Slack) 살아있는지 |
| `python scripts/test_hubspot_inbound.py` | HubSpot 에 테스트 contact 만들었다 지우면서 인바운드 전체 흐름 검증 |
| `python scripts/run_inbound.py <contact_id> --message "..."` | **실제 운영용** — 이미 있는 HubSpot contact 에 대해 인바운드 처리 |
| `python scripts/init_db.py` | DB 마이그레이션 (한 번만, 또는 마이그레이션 추가 시) |

## 시나리오별 테스트

### 1. 단위 테스트 (외부 의존 없음, 빠름)

```powershell
.venv\Scripts\python.exe -m pytest -q
```

기대: `170 passed`. 실패하면 코드 어딘가가 깨져 있는 것.

특정 영역만 보려면:
```powershell
.venv\Scripts\python.exe -m pytest tests/test_inbound_flow.py -q     # 인바운드만
.venv\Scripts\python.exe -m pytest tests/test_knowledge.py -q        # knowledge_base 로더만
.venv\Scripts\python.exe -m pytest tests/test_hubspot.py -q          # HubSpot 클라이언트만
```

### 2. 환경 사전점검

```powershell
.venv\Scripts\python.exe -m src.cli doctor
```

확인 항목: `.env` 존재, DB 파일/연결, claude CLI, HubSpot 토큰, Slack 설정, YouTube 키, SMTP. 빨간 `[XX]` 가 뜨는 항목이 있으면 그것부터 채우기.

### 3. 실연결 헬스체크

```powershell
.venv\Scripts\python.exe -m src.cli healthcheck
```

`doctor` 보다 한 발 더 — 실제 API 호출이 200 으로 돌아오는지까지 확인. Supabase Postgres 도 여기서 검증됨.

### 4. HubSpot 자동 contact + 인바운드 end-to-end (dry-llm)

LLM 호출 없이 토큰 / DB / 흐름만 빨리 확인:

```powershell
.venv\Scripts\python.exe scripts\test_hubspot_inbound.py --dry-llm
```

10초 안에 5단계 모두 PASS 떨어져야 함:
- 토큰 검증
- 테스트 contact 생성
- InboundAgent 실행 (mock LLM)
- DB 결과 출력
- 테스트 contact 삭제

### 5. 진짜 LLM 으로 인바운드 (1–2분)

```powershell
.venv\Scripts\python.exe scripts\test_hubspot_inbound.py --message "월 사용료가 얼마인가요?"
```

LLM 이 `pricing_question` 으로 분류 → `knowledge_base/pricing_example.md` 참조 → 미팅 제안 한국어 초안 작성. 결과의 `body_preview` 가 자연스러운 한국어인지 + 시그니처가 `김규원 / perso / Intern / devrel.365@gmail.com` 으로 잘 들어가는지 확인.

다른 카테고리도 테스트:
```powershell
# 파트너십 문의
.venv\Scripts\python.exe scripts\test_hubspot_inbound.py --message "리셀러 파트너십을 제안드리고 싶습니다."

# 채용 문의  
.venv\Scripts\python.exe scripts\test_hubspot_inbound.py --message "혹시 채용 중이신가요?"

# 영문 문의
.venv\Scripts\python.exe scripts\test_hubspot_inbound.py --message "Hi, can you send your pricing? We are a Singapore-based startup."
```

각각 `category`, `score`, 답장 언어(`language`)가 달라지는지 확인.

### 6. 실제 contact 처리 (운영 시나리오)

테스트 계정에 contact 를 **HubSpot UI 에서 직접 만들고** 그 ID 로 처리:

1. https://app.hubspot.com/contacts/246205524 접속
2. **Create contact** → 이메일/이름 입력 → 저장
3. URL 끝의 숫자 (contact ID) 복사 — 예: `486411754228`
4. 노트북에서:
   ```powershell
   .venv\Scripts\python.exe scripts\run_inbound.py 486411754228 --message "고객이 보낸 메시지 전문"
   ```

스크립트가 contact 를 생성/삭제하지 않고 그대로 둠 (실 운영용).

이메일만 알아도 됨:
```powershell
.venv\Scripts\python.exe scripts\run_inbound.py --by-email customer@example.com --message "..."
```

### 7. Supabase 에서 결과 확인

위 단계가 끝나면 Supabase 대시보드에서:

1. https://supabase.com/dashboard → 본인 프로젝트 선택
2. 좌측 **Table Editor**
3. `messages` 테이블 → 최신 row 클릭 → `subject`, `body` 컬럼이 LLM 이 만든 초안

다른 사람도 프로젝트 멤버로 초대하면 같은 화면에서 데이터 확인 가능 (Settings → Team → Invite).

### 8. knowledge_base 매칭 동작 확인

이 시스템의 핵심 기능 중 하나 — 카테고리별로 회사 안내 문서를 자동 매칭하는지.

a) 새 정책 문서 만들기:
```powershell
notepad knowledge_base\환불정책.md
```

내용:
```markdown
---
title: 환불 정책
categories: [support, pricing_question]
---

# 환불 정책

- 결제 후 7일 이내: 100% 환불
- 7–30일: 사용분 차감 후 환불
- 30일 이후: 환불 불가, 다음 결제 주기 해지만 가능
```

b) 환불 관련 문의로 LLM 호출:
```powershell
.venv\Scripts\python.exe scripts\test_hubspot_inbound.py --message "지난 주에 결제했는데 환불 받을 수 있나요?"
```

c) 답장 본문에 "7일", "환불" 등의 문구가 인용된 형태로 등장하면 매칭 성공.

d) 무관한 카테고리에서는 안 들어가는지 확인:
```powershell
.venv\Scripts\python.exe scripts\test_hubspot_inbound.py --message "혹시 채용 중이신가요?"
```

→ `recruiting` 으로 분류되어 환불정책.md 가 답장에 안 끼어들어야 함.

### 9. 톤 규칙 준수 검증

`company_rules/01_tone.md` 에 적힌 규칙들이 답장에 반영되는지 확인:

- "안녕하세요, perso의 김규원입니다." 로 시작?
- "감사합니다." 로 끝?
- 이모지가 없는지?
- "업계 1위", "최고의" 같은 과장 표현이 없는지?
- 모호한 약속 ("저희가 다 도와드리겠습니다") 없이 구체적 next step 제시?

다 통과하면 톤이 일관됩니다.

## 잘 안 될 때

| 증상 | 원인 / 해결 |
|---|---|
| `pytest` 실패 | `pip install -r requirements.txt` 다시 해보고, 그래도 안 되면 어떤 테스트가 실패하는지 알려주세요 |
| `cp949 codec can't decode` | Windows 인코딩 문제. `set PYTHONIOENCODING=utf-8` 한 뒤 재시도 |
| HubSpot `401 Unauthorized` | `.env` 의 `HUBSPOT_PRIVATE_APP_TOKEN` 확인 (PAK 아니라 `pat-na1-...` 형식) |
| HubSpot `403 Forbidden` | Private App 의 Scopes 빠짐 — `crm.objects.contacts.read/write` 등 추가 |
| `could not translate host name` (Supabase) | Direct connection 쓰지 말고 Session Pooler URL 로 교체 (`docs/배포.md` 2-2 참고) |
| LLM 호출이 한국어 시그니처 비워둠 | `company_rules/01_tone.md` 에 placeholder (`{{회사명}}`) 가 남아있는지 확인 |
| `claude CLI` 가 timeout | 프롬프트가 너무 길거나 claude 측 일시 장애. 1분 뒤 재시도 |

추가 문제는 `docs/문제해결.md` 도 함께 확인하세요.
