# 설정

실제 값은 Git에 올리지 않는 `.env`에 넣고, 키 목록은 `.env.example`을 기준으로 합니다.

## 필수

- `INTERNAL_API_TOKEN`: 내부 JSON API 보호
- `GOOGLE_CREDENTIALS_JSON`, `GOOGLE_CLOUD_PROJECT`: Vertex AI
- `HUBSPOT_PRIVATE_APP_TOKEN`: 연락처·티켓·활동 읽기/쓰기
- `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL`: 실제 이메일 발송

이메일은 SMTP로 발송합니다. HubSpot CRM 이메일 API는 실제 배달 수단이 아니라 전송 성공 후 타임라인 기록 용도입니다.

## 현재 개발자 HubSpot 계정

```env
HUBSPOT_TICKET_STAGE_NEW=1
HUBSPOT_TICKET_STAGE_AFTER_SEND=2
```

현재 계정의 `2`는 `Waiting on contact` 임시 단계입니다. 실제 계정에 `Meeting link sent`를 만든 뒤 해당 내부 ID로 교체합니다.

## 폴러와 워커

```env
INBOUND_POLL_ENABLED=true
INBOUND_POLL_INTERVAL_SECONDS=600
INBOUND_AUTO_ACK_ENABLED=true
SEND_WORKER_ENABLED=true
```

폴러는 `createdate`가 아니라 HubSpot 티켓의 최종 변경 시각을 기준으로 `New` 단계를 조회합니다. 따라서 다른 단계에서 생성된 뒤 `New`로 이동한 문의도 복구 대상입니다. Webhook 앱에는 `ticket.creation`과 `ticket.propertyChange`(`hs_pipeline_stage`) 구독을 등록합니다.

## Google Sheets를 내 계정으로 연결

조직 정책 때문에 서비스 계정을 시트 편집자로 추가할 수 없으므로 Google 사용자 OAuth를 사용합니다.
**Google Sheets API는 아이디·비밀번호 인증이 없습니다.** 내 계정으로 붙이려면 동의 화면을 한 번
거쳐 refresh token을 받아야 하고, 그 토큰을 `.env`에 넣어두면 그 뒤로는 아무도 연결 버튼을 누를
필요가 없습니다(재배포·DB 초기화 후에도 유지).

### 1) Google Cloud에서 OAuth 클라이언트 만들기 (최초 1회)

1. <https://console.cloud.google.com> → 상단에서 프로젝트 선택(없으면 새로 만들기).
2. **APIs & Services → Library** → `Google Sheets API` 검색 → **Enable**.
3. **APIs & Services → OAuth consent screen**
   - User Type: Workspace 계정이면 **Internal**(동의 심사 불필요). 개인 Gmail이면 External →
     Test users에 본인 주소 추가.
   - Scopes에 `https://www.googleapis.com/auth/spreadsheets` 추가.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**
   - Application type: **Web application**
   - Authorized redirect URIs에 아래 두 개를 등록합니다. 첫 번째는 아래 CLI가 쓰는 주소이기도
     해서 한 번 등록으로 둘 다 처리됩니다.
     - `http://127.0.0.1:8000/integrations/google-sheets/callback`
     - `<PUBLIC_BASE_URL>/integrations/google-sheets/callback`
5. 발급된 값을 `.env`에 넣습니다.

```env
GOOGLE_SHEETS_OAUTH_CLIENT_ID=...apps.googleusercontent.com
GOOGLE_SHEETS_OAUTH_CLIENT_SECRET=GOCSPX-...
```

### 2) refresh token 발급 (최초 1회)

```powershell
.\.venv\Scripts\python.exe scripts\connect_google_sheets.py
```

브라우저가 열리면 **시트를 편집할 수 있는 계정**으로 로그인해 동의합니다. 터미널에 `.env`에
넣을 두 줄이 출력됩니다. `--write-env`를 붙이면 `.env`를 직접 갱신하고, 앱이 8000번 포트를
쓰고 있으면 `--port 8765`처럼 다른 포트를 지정할 수 있습니다(그 주소도 리디렉션 URI에 등록 필요).

```env
GOOGLE_SHEETS_OAUTH_REFRESH_TOKEN=1//0e...
GOOGLE_SHEETS_ACCOUNT_EMAIL=me@estsoft.com
```

서버를 재시작하면 `파이프라인 연동관리 → Google Sheets 연결`에 `me@estsoft.com 연결됨 · .env`로
표시되고, 연결 버튼은 사라집니다. 배포 환경에는 Render 대시보드 Environment 탭에 같은 두 값을
넣습니다. refresh token은 비밀번호와 동급이니 커밋하지 마세요(`.env`는 gitignore 대상).

이 방식에서는 `SESSION_SECRET`과 `GOOGLE_TOKEN_ENCRYPTION_KEY`가 필요 없습니다 — 브라우저
왕복이 없어 서명할 state도, DB에 암호화해 저장할 것도 없기 때문입니다. 반대로 `GOOGLE_SHEETS_
OAUTH_REFRESH_TOKEN`을 비워두면 기존 브라우저 연결 방식이 그대로 동작하고, 그때는 두 값이
다시 필수가 됩니다. 연결을 끊으려면 환경변수를 비우세요(`.env` 연결 상태에서는 화면의
`연결 해제` 버튼이 동작하지 않습니다 — DB 행을 지워도 env가 이깁니다).

사이트는 `Inbound DB`와 `수주 DB`만 스키마에 맞춰 동기화합니다. `Inbound 퀄리티 분석`은 수식·차트를 보존하기 위해 읽기 참고용으로만 취급합니다. 기존 행을 사이트 이력으로 가져오는 동작은 수동 `시트 읽기·동기화`에서만 수행합니다.

시트 문서 자체는 `GOOGLE_SHEETS_SPREADSHEET_ID`(`src/common/config.py`)로 지정합니다. 기본값이
현재 워크북 ID이고 `.env`에는 없으므로, 다른 문서로 바꾸려면 `.env`에 이 키를 추가하세요.

## 문의 파이프라인 단계

보드 컬럼은 아래 7개가 전부이며 순서도 같습니다. HubSpot의 [B2B] AI Dubbing 티켓 파이프라인과
1:1로 대응하고, 로컬 키는 `PIPELINE_STAGES`(`src/api/web/routes/customer_ops.py`)에 있습니다.

| 순서 | 라벨 | 로컬 키 | 환경변수 |
| --- | --- | --- | --- |
| 1 | New | `new` | `HUBSPOT_TICKET_STAGE_NEW` |
| 2 | Meeting Link Sent | `meeting_link_sent` | `HUBSPOT_TICKET_STAGE_MEETING_LINK_SENT` |
| 3 | Negotiating | `negotiation` | `HUBSPOT_TICKET_STAGE_NEGOTIATING` |
| 4 | Reminder Sent | `reminder_sent` | `HUBSPOT_TICKET_STAGE_REMINDER_SENT` |
| 5 | Won | `won` | `HUBSPOT_TICKET_STAGE_WON` |
| 6 | Lost | `closed_lost` | `HUBSPOT_TICKET_STAGE_LOST` |
| 7 | Closed | `closed` | `HUBSPOT_TICKET_STAGE_CLOSED` |

`follow_up_needed`, `contracted`, `onboarding`, `active`는 마이그레이션 0040에서 폐기됐습니다.
뒤의 세 개는 원래 단계가 아니라 계약 상태(`contracted`/`active`)가 단계 칸으로 새어 들어간
것이었고, 이제 계약을 저장해도 보드 단계는 바뀌지 않습니다(고객 상태만 갱신). 단계를 추가하려면
`PIPELINE_STAGES`와 `stage_sync.LOCAL_STAGE_TO_SETTING`을 함께 고쳐야 하며, 시트에 쓰려면
`google_sheets._STAGE_VALUES`와 `sheet_sync._local_stage` 양쪽에 같은 값을 넣어야 합니다.

카드는 드래그 앤 드롭으로 옮기고, 드롭다운은 동일 동작의 대체 수단으로 남아 있습니다.

## Slack

기본값은 완전 비활성화입니다.

```env
SLACK_ENABLED=false
APPROVAL_CHANNEL=none
```

답변 초안이 준비된 순간에만 알림을 받으려면 토큰과 채널 ID를 설정한 뒤 두 값을 각각 `true`, `slack`으로 바꿉니다. 동일 초안은 DB의 알림 상태로 한 번만 전송됩니다. 접수 확인 메일, 테스트, 정기 보고서는 Slack으로 보내지지 않습니다. `SLACK_ENABLED=false`이면 토큰과 채널 ID가 남아 있어도 전송하지 않습니다.
